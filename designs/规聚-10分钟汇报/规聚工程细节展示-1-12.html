细节 01 · 任务追踪TRACEABILITY · 03 / 15
01 · TaskEnvelope / Run Manifest

每次任务都有执行记录

Agent 不只是吐出一个答案，而是形成一条可以检查的执行链。

  • 01
    记录任务目标把当前工作区、引用、工作流和输出要求放进 TaskEnvelope。
  • 02
    记录工具过程每一次搜索、读取、改图和 Office 操作都有事件。
  • 03
    记录成果变化识别新增、修改、删除，并保留小文件前后快照。
  • 04
    必要时回滚工程师可以确认后恢复本轮修改，不必重新开始。

细节 07 · 数据工程DATA PIPELINE · 09 / 15
07 · Import / Normalize / Tile / Tag

数据进入地图前，先经过一套管线

你做的不是“把文件拖进地图”，而是把原始数据加工成可理解、可筛选、可复用的工程数据。

01 / INPUTGeoJSON / SHP识别 .shp、.dbf、.prj、.cpg 和混合路网数据。
02 / NORMALIZE字段归一自动识别路名、路线编号、道路类型和流量字段。
03 / PREPARE分类与简化按高速、国省道、农村公路、设施点自动归类并抽稀几何。
04 / INDEX行政打标道路中点匹配区县边界，补充 adcode、city_name 等属性。
05 / OUTPUT矢量瓦片生成 PBF 瓦片，进入图层树，支持后续热更新和分析。

细节 08 · 交通分析ANALYSIS · 10 / 15
08 · OD / Route / Isochrone / Export

从基础地图走向 OD、路径和等时圈分析

地图能力继续向交通规划专题分析延伸，临时结果可以查看，也可以固化成成果。

  • OD
    流量热力与期望线读取起点、终点、流量字段，统计 OD 数、总量和峰值。
  • R
    路径规划支持驾车、步行、骑行，结果包含路径、距离和时间。
  • ISO
    等时圈分析按时间或距离生成可达范围，可进行多档对比。
  • OUT
    结果固化输出地图分析结果，并生成 HTML / PNG / 报告图。
OD → 热力 → 期望线 → 出图视频流程位
建议录制一条 45 秒真实数据链路

细节 09 · Agent 改图AGENT × MAP · 11 / 15
09 · map_read / map_edit / map_import

Agent 可以直接协作修改地图

工程师只描述意图，Agent 读取地图状态，再把修改落到样式、图层和数据上。

map_edit修改显隐、颜色、线宽、透明度、图层顺序。
map_import导入工作区 GeoJSON，自动生成瓦片并加入图层树。
