# 06 规划选址和用地预审论证报告模板

## 一、文档定位与适用场景

**用途**：交通线性工程（高速公路、国省道、互通）或点状工程，向自然资源部门申请规划选址和用地预审时的核心论证文件。报告的核心使命不是"证明项目好"，而是**证明"这个位置非占不可、占了有交代"**——即合规性、不可避让性、占补平衡、集约节约四重论证。

**适用对象**：自然资源和规划主管部门（审批）、发改部门、项目建设单位。
**案例出处**：235国道松阳武松交界至西屏段改建工程论证报告、上三高速公路增设天台东互通工程规划选址和用地预审论证报告（送审稿）、台金高速公路增设仙居西互通工程、诸暨至义乌高速公路补充论证报告（城规所/公路选址论证/）。

**篇幅**：60-100 页（含附件附图）。

## 四、逐章写作要点

### 第1章 建设项目概况
- **1.1.1 立项背景**：三段式——项目在路网中的位置（"上三高速公路是浙江省高速公路网'两纵两横十八连三绕三通道'中的重要一连，是国家高速公路网常台高速公路的组成部分，北起…南至…"）→ 区域发展需求 → 项目由来
- **1.1.2 建设依据**：规划依据（上位规划）+ 审批依据（立项文件、可研批复）
- **1.1.3 建设意义**：分区域/产业/民生三条，每条一句
- **1.2.2 项目概述**：必给技术标准表（设计速度、路基宽度、车道数、最大纵坡、最小缓和曲线长等指标逐行对照规范值），互通类项目给出匝道长度、桥梁座数、连接线长度
- **1.4 论证依据四层**（全库通用）：
  ```
  1.4.1 法律法规：《土地管理法》《城乡规划法》《基本农田保护条例》…
  1.4.2 政策文件：《自然资源部关于做好占用永久基本农田重大建设项目用地预审的通知》（自然资规〔2018〕3号）…
  1.4.3 行业规范标准：《公路工程技术标准》（JTG B01-2014）《公路路线设计规范》（JTG D20-2017）…
  1.4.4 项目资料：可研报告、初步设计、地形图、用地预审申请文件…
  ```
- **1.5 论证内容和技术路线**：一句话概括论证框架 + 技术路线框图

### 第2章 拟选址方案及空间规划符合性分析（全报告核心）
- **2.1 选址控制因素**：地形地质、城镇规划、既有设施、生态敏感区、基本农田分布——逐项列出
- **2.2 空间规划符合性**：逐一对标（生态保护红线准入→国土空间规划→交通规划→控规），每项结论"符合/不冲突"
- **2.3 重大影响因素分析**（不可避让性论证，灵魂章节）：
  - 每类敏感要素独立小节：占用情况（面积、图斑）→ 避让可能性分析（绕行方案技术经济比较）→ 结论"难以避免占用"
  - 句式模板："本项目为线性工程，起终点已基本确定，具有区域分布连续性和不可分割性，并受地形、地质、城镇规划等条件影响，线路选址有很大的局限性，通过方案比选，难以避免占用永久基本农田（示范区）和跨越生态保护红线。"
- **2.4 方案比选结论**：备选方案技术经济对比表 + 推荐方案理由（3-5条）

### 第3章 占用耕地和永久基本农田情况
- **3.1**：数据必给——占用总面积、耕地面积（分水田/旱地）、永久基本农田图斑数、平均质量等别、平均坡度；占比率（"耕地占总用地面积的72.88%"）
- **3.2 合法合规性**：对照允许占用的重大项目类型逐条引用文件（句式见下）
- **3.3 合理性**：从线路连续性、工程经济性、社会效益三角度论证
- **3.4 工程措施**：优化线位减少占用、桥梁替代高填方、表土剥离、节约集约设计（具体措施+预期节地量）

### 第4章 项目用地情况
- **4.2 建设用地控制指标分析**：总规模对照《建设项目用地标准》；各功能分区（主线、互通、收费站管理设施、公路服务站…）逐项列出"用地标准面积 vs 申报面积"，申报不得超标准；给出符合率

### 第5章 补划及耕地保护方案
- **5.1 补划方案**：补划数量 ≥ 占用数量（质量不降、数量不减）；补划地块位置、面积、质量等别
- **5.2 耕作层剥离再利用**：剥离面积、剥离土方量（万立方米）、堆放位置、再利用去向（"剥离后的表土用于土地整治的耕作土"）、可行性结论
- **5.3 临时用地**：选址避开基本农田原则、复垦方案、复垦费用
- **5.4 费用**：耕地开垦费、补划经费、征地补偿——逐项落实情况

### 第6章 论证结论
- **6.1 方案综述**：设计标准 + 工程方案要点（一段话）
- **6.2 规划条件**：约束性条件（用地红线、控制指标、生态要求）/ 建议性条件（景观、交通组织）
- **6.3 必要性合理性结论**：分条编号（1）（2）（3），每条"依据+事实+结论"（句式见素材库）
- **6.4 建设性意见**：交通组织问题、后续手续衔接建议

## 五、句式库（实测原文）

```
【合规性】本项目属于《浙江省综合交通运输发展"十三五"规划》中明确的省级高速公路项目，
属于《自然资源部关于做好占用永久基本农田重大建设项目用地预审的通知》（自然资规〔2018〕3号）
文件规定的允许占用永久基本农田的重大建设项目。

【不可避让性】本项目为线性工程，起终点已基本确定，具有区域分布连续性和不可分割性，
并受地形、地质、城镇规划等条件影响，线路选址有很大的局限性，通过方案比选，难以避免
占用永久基本农田（示范区）和跨越生态保护红线。业主单位和设计单位按照保护耕地、
节约集约用地及避让优先的原则，…（具体优化措施）

【数据句式】占用耕地面积X公顷（水田X公顷、旱地X公顷），涉及永久基本农田图斑X个，
平均质量等别X等、平均坡度X；耕地占总用地面积的X%。
```

## 七、常见错误与规避

1. **只讲合规不讲避让**：审批核心是"不可避让性"，必须给方案比选证据，否则直接退件
2. **数据缺项**：图斑数、质量等别、坡度、占比率缺一不可，专家必查
3. **引用过期文件**：用地预审政策更新频繁（自然资规〔2018〕3号已多次修订），送审前核对最新版
4. **补划数量不足**：补划必须"数量不减、质量不降"，且给出具体地块
5. **忽略临时用地**：施工临时用地不落实复垦方案会被一票否决
6. **结论与正文不一致**：第6章结论必须逐条呼应第2-5章数据
