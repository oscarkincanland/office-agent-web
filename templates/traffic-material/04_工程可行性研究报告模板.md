# 04 工程可行性研究报告模板（详版）

> 适用文体：公路/水运/园区/枢纽工程可研报告；编制依据《政府投资项目可行性研究报告编写通用文本（2023年版）》《建设项目可行性研究报告管理办法》
> 案例出处：温州TIR项目可研、常山县综合客运枢纽可研报告、G322/G528线位论证（涉及可行性章节对照）
> 实测字体字号：docx 解析提取自温州TIR 项目

---

## 一、文档定位与适用场景

### 1.1 写给谁

可研报告的阅读对象分四类，每一类关注的重心不同：

| 读者 | 关注重心 | 重点章节 |
|---|---|---|
| 项目主管部门（发改委/交通厅） | 立项必要性、投资合理性、合规性 | 第一章概述（含主要结论）、第二章背景必要性、第七章投融资 |
| 行业主管部门（厅/局业务处室） | 行业规划符合性、技术方案可行性 | 第二章背景必要性、第四章选址条件、第五章工程方案 |
| 投资人/出资方（地方政府/平台公司/社会资本） | 投资回报、风险可控、运营可行性 | 第六章运营方案、第七章投融资财务、第八章影响效果 |
| 评审专家（评审会成员） | 数据真实、依据充分、结论可信 | 全篇，但重点核对 1.4 主要结论、第三章需求预测、第五章方案比选、第七章财务测算 |

### 1.2 什么时候用

- 项目立项阶段：发改部门审批可研、核准可研的必备前置文件
- 资金申请阶段：申请中央预算内资金、专项债、银行贷款的依据
- 设计阶段：指导初步设计、施工图设计的纲领性文件
- 招商阶段：作为投资人招商文件的技术附件

### 1.3 与其他文体的区别

| 文体 | 编制时点 | 核心定位 | 与可研关系 |
|---|---|---|---|
| 线位论证（预可） | 立项前 | 多方案比选，推荐线位 | 可研的前置 |
| 工程可行性研究 | 立项 | 推荐方案深化论证 | 本模板 |
| 初步设计 | 立项后 | 施工图设计的过渡 | 可研的下游 |
| 交评 | 立项后/开工前 | 交通影响评价 | 与可研并行编制 |
| 选址论证 | 立项前/同期 | 用地合规性专项 | 可研的专项支撑 |

## 二、结构骨架（十章体系）

> ✅ = 必备章节；🔧 = 可选章节；标注字数占比供参考

  - ✅ 1.1.3 建设地点
  - ✅ 1.1.4 建设内容和规模

  - ✅ 1.1.7 建设工期

### 第四章 选址与建设条件（约占 10%）

## 四、逐章写作要点

### 第一章 概述

**1.1 项目概况（七要素，缺一不可）**

1.1.1 **项目名称**：规范表述 = 项目所在地 + 建设性质（新建/改建/扩建）+ 具体内容 + 性质（工程/项目）。示例：`温州××综合物流园区工程`、`常山县××客运枢纽工程`。

1.1.2 **建设单位**：写法人全称 + 法人代表 + 主营业务。涉及代建的需注明代建单位。

1.1.3 **建设地点**：写至县（市、区）+ 镇（街道）+ 村（社区）。配项目区位图（黑体 12pt 图题"图 1-1 项目区位图"）。

1.1.4 **建设内容和规模**：分条列出建设内容（道路、桥梁、堆场、仓库、综合楼等）+ 数量 / 规模 / 标准。例如：
> 本项目总占地面积约 1452 亩，总建筑面积约 86.5 万 m²，主要建设内容包括：综合物流中心 35 万 m²、公路港 18 万 m²、保税仓储 12 万 m²、海关监管区 8.5 万 m²、配套服务区 13 万 m²。

1.1.5 **主要经济技术指标**：表格形式，列出占地、建筑、容积率、绿化率、投资、税收、就业等指标。示例见表 1-1。

1.1.6 **投资规模及资金来源**：写明总投资额 + 资金来源构成（中央投资 / 省级补助 / 地方自筹 / 银行贷款 / 社会资本）。

1.1.7 **建设工期**：明确开工年 + 完工年 + 总工期（月）。

**1.2 项目单位概况**：建设单位简介（300-500 字），包括组建背景、注册资本、主营业务、组织架构、近三年财务状况、已建 / 在建项目情况。

**1.3 编制依据（四层结构）**

1. 法律法规层：列举国家法律、行政法规、部门规章
2. 政策文件层：列举国家、省、市相关政策文件
3. 规范标准层：列举行业标准、规范、规程
4. 项目资料层：列举上位规划、批复文件、专题报告、评估文件

**写法模板**：
```
本报告编制依据：
（1）法律法规：《中华人民共和国公路法》《中华人民共和国土地管理法》《政府投资条例》（国务院令第712号）。
（2）政策文件：《××省综合交通运输发展"十四五"规划》（×政发〔2021〕×号）。
（3）规范标准：《公路工程技术标准》（JTG B01-2014）、《公路路线设计规范》（JTG D20-2017）。
（4）项目资料：《××市国土空间总体规划（2021-2035年）》、本项目立项批复（×发改基础〔2024〕×号）、《项目建议书》（××设计院，2024年3月）。
```

**1.4 主要结论（五要素）**

主要结论是决策者 5 分钟读完的压缩版，必须包含五要素：
- ① 项目定位句
- ② 技术标准句
- ③ 推荐方案句
- ④ 投资估算句
- ⑤ 效益评价句

**写法模板**（参考温州 TIR / 常山可研）：
> 本项目的建设是落实国家"一带一路"倡议和长江经济带发展战略的必然要求，是完善区域综合交通运输体系、补齐多式联运短板的重要引擎，是打造浙南闽北赣东物流枢纽、推动区域经济高质量发展的关键抓手。项目推荐方案为××线位方案（K 方案），全长约 45.6 公里，按双向六车道一级公路标准建设，设计速度 80km/h。项目估算总投资 86.5 亿元，其中建安费 62.3 亿元。财务评价结果表明，项目税前财务内部收益率 6.8%，投资回收期 14.2 年，抗风险能力较强。项目实施后可显著提升区域运输服务能力，社会经济效益良好，建议尽快组织实施。

### 第二章 项目建设背景与必要性

**2.1 建设背景（四层背景，逻辑自上而下）**

- 国际背景：1-2 段，约 200 字
- 国家背景：2-3 段，约 400 字（"一带一路"、京津冀协同发展、粤港澳大湾区、长江经济带、长三角一体化等）
- 省级背景：2-3 段，约 400 字
- 市级背景：1-2 段，约 200 字

**句式库**：
- 国际层："当前，全球供应链格局加速重构，区域全面经济伙伴关系协定（RCEP）正式生效，国际贸易通道竞争日益激烈……"
- 国家层："党的二十大报告提出加快建设交通强国；党中央《建议》强调：'加快建设国家综合立体交通网'；国家《"十四五"现代综合交通运输体系发展规划》明确……"
- 省级层："《××省综合交通运输发展"十四五"规划》提出构建'X 轴 X 廊 X 枢纽'格局，省委《建议》要求'打造全国一流现代化综合交通体系'……"
- 市级层："××市第六次党代会提出建设'区域中心城市、物流枢纽城市'的战略目标，市政府工作报告明确'加快推进××综合物流园区建设'……"

**2.3 必要性（四个维度）**

| 维度 | 内容 | 关键词 |
|---|---|---|
| 国家战略需要 | 落实国家重大战略的要求 | "必然要求"、"战略支撑" |
| 行业发展需要 | 补齐行业短板、完善网络 | "重要引擎"、"关键环节" |
| 地方经济需要 | 拉动区域经济发展 | "迫切需要"、"现实选择" |
| 民生改善需要 | 服务群众出行/产业升级 | "民心所向"、"发展所需" |

**必要性句式库**：

| 句式 | 适用维度 | 例句 |
|---|---|---|
| 是……的必然要求 | 国家战略 | "本项目建设是落实国家'一带一路'倡议、推动长江经济带高质量发展的必然要求" |
| 是……的重要引擎 | 行业发展 | "本项目建设是补齐区域多式联运短板、打造综合立体交通网的重要引擎" |
| 是……的关键抓手 | 地方经济 | "本项目建设是推动××产业升级、打造区域经济新增长极的关键抓手" |
| 是……的迫切需要 | 民生改善 | "本项目建设是解决群众出行难问题、服务城乡一体化发展的迫切需要" |

### 第三章 需求分析

**3.1 项目功能定位**

定性的功能描述：项目在综合交通体系中的地位 + 服务对象 + 服务范围（直接腹地 / 间接腹地）。

**3.2 社会经济发展趋势分析**

GDP 增速、产业结构、人口变化、城镇化率。配"表 3-1 ××市近五年经济社会发展指标表"。

**3.3 产业需求分析**

主导产业 + 物流需求 + 上下游配套。配产业布局图。

**3.4 物流/客货需求预测**

预测方法："四阶段法（生成-分布-分配）+ 增长率法 + 类比分析法"组合。
特征年：现状年 + 近期（5 年）+ 远期（15-20 年）。
预测结果：分货类、分流向。配"表 3-2 ××市货运量预测表"。

### 第四章 选址与建设条件

**4.1 拟建地点**

文字描述 + 项目区位图。

**4.2 建设条件**

- 自然条件：气象（气温、降水、风向）、水文（河流、水位）、地质（地层、岩性、地震烈度）、地形地貌
- 交通条件：现状公路、铁路、水运、航空
- 公用工程条件：给水、排水、供电、供气、通信

### 第五章 工程方案

**5.1 设计原则与标准**

设计原则：安全、耐久、节能环保、经济美观、便于施工养护。
技术标准：列出路线等级、设计速度、车道数、路基宽度、路面结构、桥梁荷载等级、抗震设防烈度。

**5.2 总平面布置/路线方案**

推荐方案描述 + 平面图。

**5.3-5.6 分项设计**

- 路基路面：路基高度、边坡坡率、路面结构层（面层/基层/底基层）、材料
- 桥涵：桥位选择、桥型方案、跨径布置、桥长
- 隧道：隧址选择、洞门型式、衬砌结构、通风照明
- 交叉：互通立交、分离立交、通道、天桥
- 公用工程：给排水、电气、暖通、通信

### 第六章 运营方案

**6.1 运营模式**

BOT / BT / TOT / 政府自营 / 委托运营。
运营机构：业主自营 / 委托第三方 / 联合运营。

**6.2 交通流线组织**

外部集疏运 + 内部交通组织。配"图 6-1 交通流线组织图"。

**6.3 建设管理**

建设单位 + 设计单位 + 施工单位 + 监理单位。质量管理、进度管理、安全管理。

**6.4 安全保障**

应急预案 + 风险管控 + 重大危险源辨识。

## 七、常见错误与规避

| 错误 | 表现 | 规避 |
|---|---|---|
| 必要性虚化 | 大段引用政策文件，缺乏项目层面论证 | 每条必要性都要落到项目本身（"本项目"句式贯穿） |
| 编制依据不全 | 缺少法律层或项目资料层 | 四层结构齐备：法律/政策/规范/项目资料 |
| 项目概况缺项 | 七要素缺一（如缺建设工期） | 七要素逐项对照填写 |
| 主要结论模糊 | 不给数字、不给结论 | 五要素必须齐全，量化指标必须给出 |
| 投资估算粗放 | 无分项估算、无单价依据 | 分项到 8-10 项，单价列依据 |
| 财务评价缺失 | 只算总投资、不算收益率 | 财务内部收益率、净现值、投资回收期必算 |
| 图表编号混乱 | 图 1-1 与图 2-1 重号 | 按章连续编号 |
| 字体字号不统一 | 章标题与节标题同字号 | 章 16pt 加粗、节 14pt 加粗、正文 14pt 不加粗 |
| 缩进不一致 | 章缩 32、节缩 28、正文缩 28 | 三级缩进体系固定 |
| 范围符号错误 | 用全角"～"或中文"至" | 用半角连字符"-"或波浪号"~" |
| 缺章前概述 | 跳到第二章背景，缺 1.4 主要结论 | 1.4 必须置于第一章末尾 |
| 数据无来源 | 表格数据不标出处 | 表下"注：数据来源于 ××。" |
| 时间表述混乱 | 封面用阿拉伯数字 | 封面用汉字"二〇二六年一月"，正文用阿拉伯 |
| 缺表注 | 表格缺少"注："说明 | 每张表格下加注 |
| 缺图注 | 图件缺少图题和编号 | 每张图下加图题，按章连续编号 |
| 项目定位不准 | 跨章节出现"项目名称"不一致 | 1.1.1 名称全篇统一使用 |
| 缺"建议"章节 | 仅给结论不给建议 | 第九章必含结论 + 建议两节 |
