# 05 线位论证（预可）报告模板（详版）

> 适用文体：公路/铁路工程线位比选论证报告（工可阶段前的方案比选文件），亦称"预可研"
> 案例出处：G322 衢州至衢江段公路改建工程线位论证报告、G528 国道线位论证报告
> 实测字体字号：PDF 解析提取自线位论证案例；正文 14pt、节标题 16pt、注 10.5pt

---

## 一、文档定位与适用场景

### 1.1 写给谁

线位论证报告的核心读者为决策层与评审专家，特点是"决策导向、可比可判"。

| 读者 | 关注重心 | 重点章节 |
|---|---|---|
| 项目主管部门 | 立项必要性、推荐方案合理性 | 1.5 主要结论、第六章推荐方案 |
| 评审专家 | 方案比选依据、技术指标可比性 | 第四章交通量预测、第五章技术标准、第六章方案比选 |
| 沿线政府/部门 | 对地方的影响与利益协调 | 第二章现状、第六章建设方案 |
| 后续设计单位 | 关键控制点与技术指标 | 1.4 必要性、第六章推荐方案、第七章投资估算 |

### 1.2 什么时候用

线位论证（预可）位于"项目建议书 → 工可研 → 初设"链条前端：

```
项目建议书（立项）→ 线位论证 / 预可研（多方案比选） → 工程可行性研究（推荐方案） → 初步设计 → 施工图设计
```

触发条件：
- 新建公路 / 铁路项目，长度大于 30km 或投资大于 20 亿元
- 涉及多个县（市、区）或穿越多个敏感区（生态红线、永久基本农田、饮用水源保护区）
- 存在 2 条以上可行线位方案，需要量化比选
- 前期立项阶段需要确定主要控制点和技术标准

### 1.3 与工可研的关系

| 文体 | 阶段 | 方案数量 | 重点 | 与线位论证关系 |
|---|---|---|---|---|
| 项目建议书 | 立项 | 概念性 | 必要性 | 前置 |
| **线位论证 / 预可** | **方案定型** | **2-4 个备选** | **方案比选** | **本模板** |
| 工可研 | 立项 | 1 个推荐 | 方案深化 | 下游 |
| 初设 | 开工前 | 1 个确定 | 工程细化 | 下游 |

线位论证的输出："1 个推荐方案 + 比选过程 + 关键控制点 + 技术标准 + 投资估算"。

## 四、逐章写作要点

### 第一章 概述

**1.1 项目背景**

1-2 段，300-500 字。说明项目所在区域 + 现状瓶颈 + 上位规划依据 + 项目由来。
典型句式：
> ××公路是××省"十四五"综合交通运输发展规划的重点项目，是连接××市与××市的干线公路，是××通道的重要组成部分。现状××公路为二级公路标准，技术等级低、通行能力不足，难以满足日益增长的交通需求，亟需实施改建。××省发展和改革委员会以×发改基础〔2023〕×号文件批复同意本项目开展前期工作。

**1.2 编制依据**

四层结构（参见 04 可研模板）：法律/政策/规范/项目资料。线位论证侧重：
- 法律：《公路法》《土地管理法》
- 政策：《国家公路网规划》《××省综合交通运输发展"十四五"规划》
- 规范：《公路工程技术标准》（JTG B01-2014）、《公路路线设计规范》（JTG D20-2017）、《公路工程项目可行性研究报告编制办法》
- 项目资料：项目建议书批复、相关专题报告、沿线政府意见

**1.3 研究过程**

时间线叙述：接任务 → 现场踏勘 → 收集资料 → 方案拟定 → 部门对接 → 专家咨询 → 方案优化 → 报告编制。每个阶段 1-2 句话，配时间节点。

**1.4 必要性**

四个维度（与可研同构）：
- 是……的必然要求
- 是……的重要引擎
- 是……的关键抓手
- 是……的迫切需要

**1.5 主要结论（六要素，最关键章节）**

> ⚠ 1.5 主要结论是决策者 5 分钟读完的压缩版，必须包含六要素，缺一不可。

六要素：
- ① 交通量预测结果（特征年交通量、增长率）
- ② 技术标准（路线等级、设计速度、车道数、路基宽度）
- ③ 起终点与主要控制点
- ④ 推荐线位方案（K 方案 / A 方案 / B 方案）
- ⑤ 建设规模（路线长度、桥梁座数、隧道座数、互通座数）
- ⑥ 投资估算（总投资、每公里造价）

**写法模板**：
> 本项目是××省"十四五"综合交通运输发展规划的重点项目，是完善××通道、提升区域路网通行能力的迫切需要。
> 
> 交通量预测：××公路××段现状交通量为 12450 pcu/d（2023 年），预测特征年 2030 年为 18650 pcu/d，2040 年为 24580 pcu/d，年均增长率 3.8%。
> 
> 技术标准：本项目按双向六车道一级公路标准建设，设计速度 80km/h，路基宽度 32m，桥梁荷载等级公路-Ⅰ级。
> 
> 起终点与控制点：起点位于××县××镇××村（K0+000），终点位于××区××镇××村（K45+600）。主要控制点包括××互通、××特大桥、××隧道、××枢纽。
> 
> 推荐方案：经综合比选，推荐 K 方案（北线方案），路线全长 45.6 公里，较 A 方案（南线方案）长 2.3 公里，但可避让××生态保护红线、节省投资 4.8 亿元。
> 
> 建设规模：推荐方案主线桥梁 8650m/18 座，隧道 4250m/3 座，互通立交 4 处，平面交叉 6 处。
> 
> 投资估算：项目估算总投资 86.5 亿元，平均每公里造价 1.90 亿元；资金来源包括中央投资、省级补助、地方自筹、银行贷款。

**压缩版首段写法**（仅 5 行内呈现决策结论）：
> 综合分析认为，本项目是落实国家战略、完善区域路网、服务地方发展的必要工程。预测 2040 年交通量达 24580pcu/d，宜按双向六车道一级公路标准建设。推荐 K 方案，路线全长 45.6 公里，估算总投资 86.5 亿元。建议尽快启动工可研编制工作。

### 第三章 交通量预测（核心章节）

**3.1 交通量调查与分析**

调查方法：OD 调查 + 断面交通量观测 + 运输量统计。
数据来源：收费站数据、统计年鉴、典型调查。
分析：现状交通量构成（客车 / 货车 / 拖挂 / 集装箱）、货类构成、流向分布。

**3.2 预测思路与方法**

预测思路："四阶段法 + 增长率法 + 类比分析法"组合。

**特征年设定**（线位论证通用规范）：
- 现状年：2023 年
- 近期特征年：2030 年（通车后 5-7 年）
- 远期特征年：2040 年（通车后 15-20 年）
- 预测基年：项目开工年

**3.3 交通量生成预测**

方法：弹性系数法 + 回归分析法。
公式：T = T₀ × (1 + ε × α)ⁿ
其中：T 预测年交通量、T₀ 基年交通量、ε 弹性系数、α GDP 增长率、n 年数。

**3.4 交通量分布预测**

方法：Fratar 模型 + 重力模型。
输出：OD 矩阵。

**3.5 诱增与转移预测**

诱增交通：因新建公路产生的新增交通（按无此项目 OD 的 5-15% 估算）。
转移交通：从其他运输方式或平行公路转移而来的交通。

**3.6 分配预测**

方法：全有全无法 + 容量限制法 + 多路径概率分配法。
分配原则：时间最短、费用最低、舒适度最佳。

**3.7 预测结果汇总**

配"表 3-1 交通量预测结果汇总表"：

| 路段 | 2023 年（基年） | 2030 年（近期） | 2040 年（远期） | 年均增长率 |
|---|---|---|---|---|
| K0-K10 | 12450 | 16850 | 22450 | 3.6% |
| K10-K25 | 9860 | 13280 | 17680 | 3.6% |
| K25-K45 | 8240 | 11080 | 14750 | 3.6% |

### 第四章 技术标准

**4.1 设计速度**

| 地形 | 公路等级 | 设计速度 |
|---|---|---|
| 平原微丘 | 一级公路 | 80-100 km/h |
| 山岭重丘 | 一级公路 | 60-80 km/h |
| 平原微丘 | 高速公路 | 100-120 km/h |

**4.2 车道数**

依据：远景年交通量 + 设计通行能力 + 服务水平。
判定：
- 单车道日通行能力（一级公路）：55000 pcu/d
- 双向四车道一级公路通行能力：20000-30000 pcu/d
- 双向六车道一级公路通行能力：40000-55000 pcu/d
- 远景年交通量超过 20000 pcu/d 应选六车道

**4.3 服务水平**

公路服务水平分四级：
- 一级：自由流（V/C ≤ 0.6）
- 二级：稳定流（V/C = 0.6-0.8）
- 三级：饱和流（V/C = 0.8-1.0）
- 四级：强制流（V/C > 1.0）

设计标准：一般公路采用二级，高速公路采用二级。配"表 4-1 各级公路服务水平对照表"。

## 七、常见错误与规避

| 错误 | 表现 | 规避 |
|---|---|---|
| 方案过少 | 仅提 1 个方案，无比选价值 | 至少 2 个、最好 3-4 个备选方案 |
| 比选指标单一 | 只比投资和长度 | 七维比选：工程/投资/技术/质量/规划/环保/社会 |
| 1.5 主要结论缺项 | 缺交通量预测或投资估算 | 六要素全：交通量/标准/起终点/推荐/规模/投资 |
| 缺特征年 | 现状年+未来无明确特征年 | 现状年+近期（5年）+远期（15-20年） |
| 交通量预测无依据 | 直接给出数据，无方法说明 | 写明四阶段法 + 增长率法 + 类比法组合 |
| 推荐方案理由不足 | 选 K 不说明为何不选 A/B | 推荐方案必须有定性 + 定量 + 综合比较段落 |
| 占用敏感区未论证 | 推荐方案占用基本农田/生态红线未分析 | 必须单列"占用敏感区情况"分析 |
| 每公里造价缺失 | 只给总投资不给单价 | 比选表必须含"每公里造价" |
| 缺下阶段建议 | 仅提问题不给建议 | 第八章必含问题 + 建议两节 |
| 比选表无量化 | 仅定性描述"较好"、"一般" | 每个指标尽量量化或分级 |
| 桥隧比未计算 | 推荐方案未给桥隧比 | 推荐方案概述中必含"桥隧比 XX%" |
| 互通位置未论证 | 互通设置位置无说明 | 互通设置需说明服务对象 + 与城镇关系 |
| 隧道规模未分类 | 隧道未区分长/短/特长 | 按规范分类（<500m/500-3000m/>3000m） |
| 平面图缺比例尺 | 平面图无比例尺或指北针 | 每张图必备比例尺 + 指北针 |
| 缺图例 | 路线图无图例 | 路线图含图例：建成/在建/规划 |
