**规律**：
1. 主标题 = 两个四字格/六字格对仗短语（动词+目标）；年度关键词：新常态→黄金时期→强国→决胜→变革重塑→世界一流强港→勇突破开新局
2. 副标题从 2022 年起稳定为"…当好开路先锋"，前缀逐年微调（争当/奋力/全力/努力）
3. 年度行动品牌演变：2018"攻坚年"→2023"稳进提质攻坚行动"→2025"奋战冲刺年"→2026"争先奋进年"，命名逻辑 = 动作+方向+年
4. 起标题可参考的动词库：争先/奋进/突破/冲刺/攻坚/实干/重塑/领航/提能/提质

## 二、通用句式素材库（全库提取）

### 1. 背景四层次句式（可研/论证）
```
【国际】受地缘政治影响，全球物流通道面临挑战，具体表现在：一是…二是…
【国家】党的二十届三中全会提出…；国务院印发《…》（国发〔2024〕X号），部署…
【省级】推进高水平对外开放，建设高能级开放强省，要求…
【市级】"世界的温州"为全省开放大局注入强劲动能，…（本地特色提法）
收束句：上述战略部署为项目提供了明确的政策依据和建设窗口期。
```

### 2. 必要性四维句式（可研）
```
① 项目是落实国家战略与响应政策部署的必然要求（政治必然性）
② 项目是促进区域发展转型和培育新质生产力的重要引擎（发展价值）
③ 项目是破解…瓶颈、补齐…短板的关键抓手（问题导向）
④ 项目是服务…战略、保障…安全的需要（功能价值）
引导句：项目建设对政策实施、地方供应链和产业链的融合发展，意义重大，必要性主要体现在以下四个方面：
```

### 3. 建设条件与问题句式（规划）
```
【成就】"十四五"综合交通投资预计较"十三五"增长35%，规模约占全省基础设施投资的50%，2次获国务院督查激励
【问题】部分通道与枢纽瓶颈制约亟待突破：沪杭甬、常台、杭宁等主干高速公路基本全线处于五级服务水平；
        千吨级航道占比较低（我省5.4%，江苏14%、广东11.7%）
【形势】从发展环境看…；从发展使命看…；从发展挑战看…
【机遇挑战】机遇：…；挑战：…（分列，各2-3条）
```

### 4. 目标指标句式
```
——交通投资全国前列。确保完成综合交通投资3500亿元、力争3600亿元，其中公路水运投资2280亿元。
——综合运输提能增效。沿海港口货物吞吐量力争17.8亿吨、集装箱吞吐量5200万标箱。
指标选取三原则：突出战略导向…；突出高质量发展导向…；突出民生导向…
论证三视角：从国家要求来看…；从我省目标来看…；从现实基础来看…
```

### 5. 任务标题句式（规划）
```
【对仗式】四、建强国际陆港枢纽，提升综合交通枢纽辐射能级
【动词前置】优网络，完善多元线网，实现功能一体
【聚焦式】一是聚焦便捷畅达，打造立体互联的基础设施体系
【政策依据+任务】党中央《建议》强调…；省委《建议》要求…；重点任务：…；主要目标：…
```

### 6. 结论段句式（可研/论证）
```
定位句：项目是支撑…的核心工程 / 在填补…空白、强化…功能、辐射…区域方面有重要作用
定量句：项目总投资X亿元，运营X年回正，期间累计净收益X亿元，具备一定经济可行性与社会价值
升华句：通道带动物流，物流兴贸易，贸易聚产业，产业促发展（顶真）
展望句：项目建设将充分释放…动能，推动"通道经济"迈向"枢纽经济"
```

## 四、蒸馏方法备忘（后续新增文档时用）

1. 目录骨架：提取所有标题行（docx 用样式名，PDF 用编号正则）
2. 格式细节：docx 用 python-docx 读字体/字号/缩进/行距；PDF 用 pdfplumber 按字号聚类
3. 行文句式：定位关键章节（必要性/结论/目标/问题），截取 600-800 字原文
4. PPT：直接解析 slide XML（python-pptx 对 WPS 文件可能失败，用 zipfile+lxml）
5. 产出：每类文档一个模板文件 + 通用规范汇总 + 句式素材库
