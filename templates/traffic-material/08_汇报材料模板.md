# 08_汇报材料模板（文字稿详版）

> 数据基础：00_格式数据汇总.md（含公文格式实测、规划汇报47页PPT骨架）
> 适用场景：领导汇报、上级汇报、专家汇报、会议汇报材料（PPT配套文字稿）
> 字数范围：正文10-20页（约 6000-12000 字）

---

## 一、文档定位与适用场景

### 1.1 写给谁

- **主受众**：听汇报的上级领导（省长/厅长/部长）、会议主席台成员、列席的部门负责人
- **次受众**：未能到会、需要事后阅知材料的其他领导（材料会作为会议附件存档）
- **核心读者画像**：① 没时间读长材料 ② 关注结论与重点问题 ③ 重视数据与逻辑闭环 ④ 关注"下一步要什么支持"

### 1.2 什么时候用

| 触发场景 | 典型场合 | 篇幅建议 |
|---|---|---|
| 五年规划编制情况汇报 | 省政府常务会、专题汇报会 | 12-15页 |
| 重大规划专题汇报 | 部级专题汇报、省委专题会 | 10-15页 |
| 重点项目谋划汇报 | 省政府重大项目专题会 | 8-12页 |
| 工作进展阶段汇报 | 半年度/年度调度会 | 6-10页 |
| 专家评审汇报 | 规划评审会、论证会 | 15-20页 |

### 1.3 与 PPT 的关系

- 本模板是**PPT 汇报的配套文字稿**，每页 PPT 下方一般附 200-400 字的口述稿
- 文字稿不是 PPT 标题的简单展开，而是**领导即席追问时可直接念出的备用段落**
- 写作时先成稿再提炼 PPT，**严禁 PPT 写完后再倒推文字稿**

## 二、结构骨架

### 2.1 四段式主结构（必备）

```
一、前期工作进展
   ├─ 启动部署阶段（年月-年月）
   ├─ 调研起草阶段（年月-年月）
   ├─ 规划编写阶段（年月-年月）
   ├─ 征求意见阶段（年月-年月）
   └─ 评审修改阶段（年月-年月）

二、规划主要内容
   （一）发展基础
       ├─ 1.发展成就（"十四五"主要成绩）
       └─ 2.存在问题（突出 3-5 项短板）
   （二）发展形势
       ├─ 1.历史方位（从历史发展看）
       ├─ 2.现实需求（从发展需要看）
       └─ 3.政策导向（从中央要求看）
   （三）总体思路与主要目标
       ├─ 1.指导思想（战略定位一句话）
       ├─ 2.基本原则（3-4 条）
       ├─ 3.主要目标（关键指标表）
       └─ 4.指标选取三原则（说明）
   （四）主要任务
       ├─ 任务1：……
       ├─ 任务2：……
       └─ ……（5-8 项任务）
   （五）拟纳规项目
       ├─ 1.项目上报情况
       ├─ 2.纳规总体原则（量化评分规则）
       ├─ 3.拟纳规项目和投资概况
       └─ 4.重大工程谋划（3-5 个）

三、若干重点问题说明
   ├─ 关于……的确定（如重大指标取数）
   ├─ 关于……的把握（如投资规模把握）
   ├─ 关于……的说明（如与上位规划衔接）
   └─ ……（3-5 个重点问题）

四、下步工作计划
   ├─ 1.……（时间节点）
   ├─ 2.……（时间节点）
   ├─ 3.……（时间节点）
   └─ 需上级支持事项（建议清单）
```

### 2.2 必备 / 可选标注

| 章节 | 标注 | 说明 |
|---|---|---|
| 一、前期工作进展 | ✅ 必备 | 时间线必呈现 |
| 二（一）发展基础 | ✅ 必备 | 成绩+问题两段式 |
| 二（二）发展形势 | ✅ 必备 | "三个看"三段式 |
| 二（三）总体思路与目标 | ✅ 必备 | 含指标表 |
| 二（四）主要任务 | ✅ 必备 | 5-8 条 |
| 二（五）拟纳规项目 | 🔧 可选 | 仅规划汇报必含 |
| 三、重点问题说明 | ✅ 必备 | 主动列出 |
| 四、下步工作计划 | ✅ 必备 | 含请求支持事项 |
| 落款：汇报单位+日期 | ✅ 必备 | 公文格式 |

### 2.3 章节字数占比建议

| 章节 | 字数占比 | 缘由 |
|---|---|---|
| 一、前期工作进展 | 10-15% | 简明扼要，不喧宾夺主 |
| 二、规划主要内容 | 60-65% | 主体，重在"主要任务" |
| 三、重点问题说明 | 15-20% | 差异化亮点，必出彩 |
| 四、下步工作计划 | 10-15% | 落点，简洁明快 |

## 三、格式规范

### 3.1 编号体系（公文式）

```
一、 → （一） → 1. → （1） → ①
```

- 一级（一、二、三、四）：黑体 16pt，加粗，独立成行
- 二级（（一）（二））：楷体_GB2312 16pt，加粗
- 三级（1. 2. 3.）：仿宋_GB2312 16pt，加粗
- 四级（（1）（2）（3））：仿宋_GB2312 16pt，**不**加粗
- 五级（① ② ③）：仿宋_GB2312 16pt，括号外

> **实测值来源**：00_格式数据汇总.md 政府规划（金华十五五）实测体系

### 3.2 字体字号表（汇报材料通用，参考公文与规划）

| 元素 | 字体 | 字号 | 加粗 | 对齐 |
|---|---|---|---|---|
| 大标题（汇报标题） | 方正小标宋简体 | 22pt | 否 | 居中 |
| 副标题（——编制情况汇报） | 楷体 | 22pt | 否 | 居中 |
| 署名（汇报单位/发言人） | 楷体 | 16pt | 否 | 居中 |
| 日期 | 楷体 | 16pt | 否 | 居中 |
| 称谓（各位领导、同志们：） | 楷体_GB2312 | 16pt | 否 | 顶格 |
| 一级标题 | 黑体 | 16pt | 否 | 顶格 |
| 二级标题 | 楷体_GB2312 | 16pt | 加粗 | 首行缩进2字符 |
| 三级标题 | 仿宋_GB2312 | 16pt | 加粗 | 首行缩进2字符 |
| 正文 | 仿宋_GB2312 | 16pt | 否 | 首行缩进2字符 |
| 关键数字 | 仿宋_GB2312 | 16pt | **加粗** | 同正文 |
| 表题/图题 | 黑体 | 12pt | 否 | 居中 |

### 3.3 页面设置

- 页面：A4（21.0×29.7cm）
- 边距：上下 2.5cm，左右 3.2cm（公文标准边距，建议值按公文通行规范）
- 行距：**固定值 29 磅**（实测值）
- 首行缩进：32pt（2字符，16pt 字号下）
- 段前段后：均为 0
- 装订位置：左侧装订，留 1cm 装订线

### 3.4 标点与数字

1. **全角标点**："，。：；！？"全部使用中文全角
2. **顿号**：并列词用"、"（"港口、机场、枢纽"）
3. **文件引用**：《文件名》（文号〔2024〕5号）
4. **政策引用句式**（必备，背诵级）：
   - "党中央《建议》强调：……"
   - "省委《建议》要求：……"
   - "部里表示：……"
5. **数字使用**：
   - 正文阿拉伯数字+单位（"2024 年""1452 亿元""16.7%""7246pcu/d"）
   - 封面日期汉字（"二〇二六年一月"）
   - 金额精确到个位（"125805 万元"）
6. **范围连接**：用半角连字符（"2021-2035 年""十四五-十五五"）
7. **破折号**：副标题与排比句使用（"——交通投资全国前列"）
8. **数字加粗规则**：
   - 总体目标的关键数字（"投资 2 万亿元""公路 6800 公里"）
   - 标志性指标（"1.3 亿人次""超 270 条"）
   - 时间节点（"2025 年""2030 年"）

### 3.5 排版禁忌

| 禁忌 | 正确做法 |
|---|---|
| 段首不缩进 | 全文首行缩进 2 字符 |
| 数字与中文混排时乱加空格 | 数字与单位间留 0.5 个汉字空格（如"1452 亿元"） |
| 英文标点混入中文段落 | 全部使用中文全角标点 |
| 段间距大于 0 | 段前段后均为 0，靠行距控制密度 |
| 表格跨页无表头 | 续表加"续表"标记并重复表头 |
| 字号忽大忽小 | 全文统一 16pt 正文，标题按层级递减 |

## 四、逐章写作要点

### 4.1 一、前期工作进展（编制历程时间线）

#### 写什么

汇报规划编制的历程，按时间顺序呈现 5 个阶段：启动部署→调研起草→规划编写→征求意见→评审修改。每阶段用 1 段（80-150 字）。

#### 写作逻辑

```
启动部署 → 调研起草 → 规划编写 → 征求意见 → 评审修改
（自上而下）（自下而上）（起草组攻坚）（多轮反馈）（修改完善）
```

#### 时间线标志节点句式

| 阶段 | 时间 | 标志节点句式 |
|---|---|---|
| 启动部署 | ×年×月 | "经××研究同意，印发《规划编制工作方案》，成立以××为组长的规划编制领导小组，下设××个专项组。" |
| 调研起草 | ×年×月-×月 | "赴××个地市、××个部门、××家龙头企业开展专题调研，形成调研报告××篇。" |
| 规划编写 | ×年×月-×月 | "组织××家规划编制单位、××名专家集中编写，形成规划初稿××万字。" |
| 征求意见 | ×年×月-×月 | "书面征求××个部门、××个地市意见；召开专家咨询会××次；网上公开征求意见××天，收到意见××条。" |
| 评审修改 | ×年×月-×月 | "通过××专家委员会评审；根据评审意见修改××轮，形成送审稿。" |

#### 完整示例（约 350 字）

> 一、前期工作进展
> 在省委、省政府高度重视和高位推动下，规划编制工作自 2023 年 6 月启动以来，按"启动部署—调研起草—规划编写—征求意见—评审修改"五个阶段有序推进。
> 一是启动部署。2023 年 6 月，省政府办公厅印发《规划编制工作方案》，成立以省长为组长，常务副省长、分管副省长为副组长的规划编制领导小组，下设综合交通、铁路、公路、水运、航空、枢纽 6 个专项组。
> 二是调研起草。2023 年 7 月至 10 月，分 3 个调研组赴全省 11 个设区市、25 个省级部门、60 余家龙头企业开展专题调研，累计召开座谈会 47 场，形成调研报告 23 篇。
> 三是规划编写。2023 年 11 月至 2024 年 6 月，组织 12 家规划编制单位、80 余名专家集中编写，形成规划文本约 18 万字、专项规划 7 项、专题研究 12 项。
> 四是征求意见。2024 年 7 月至 9 月，书面征求 36 个省级部门、11 个设区市政府意见；召开专家咨询会 4 次；通过省政府门户网站公开征求意见 30 天，收到意见建议 426 条。
> 五是评审修改。2024 年 10 月，通过省"十五五"规划专家委员会评审；根据评审意见先后修改 5 轮，形成本次送审稿。

### 4.2 二、规划主要内容

#### （一）发展基础

**写什么**：成绩 + 问题两段式

**成绩部分句式**（5-8 条）：

```
"十四五"以来，全省交通运输系统深入贯彻落实习近平总书记……
一是……（成就点 1，引用数字佐证）
二是……（成就点 2）
三是……（成就点 3）
四是……（成就点 4）
五是……（成就点 5）
```

**问题部分句式**（3-5 条短板）：

```
同时，也要清醒看到，我省交通运输发展不平衡不充分问题仍然突出：
一是部分通道与枢纽瓶颈亟待突破（如××通道能力紧张、××枢纽集疏运体系不完善）。
二是……（问题 2）
三是……（问题 3）
四是……（问题 4）
```

#### （二）发展形势

**写什么**：3 个视角的三段式分析

**"三个看"固定句式**：

```
从历史发展看，……（回顾历史方位）
从发展需要看，……（现实需求紧迫性）
从中央要求看，……（国家战略导向）
```

**完整示例（约 400 字）**：

> （二）发展形势
> 从历史发展看，"十四五"以来我省交通运输发展取得历史性成就，……（简要回顾）。站在"两个一百年"奋斗目标历史交汇点上，交通运输作为中国式现代化的开路先锋，必须率先实现现代化。
> 从发展需要看，我省正处于……的关键时期（描述发展阶段，如"经济结构优化升级、新旧动能转换"），对交通运输的支撑作用提出更高要求。……（指出需求点）
> 从中央要求看，党中央、国务院印发的《建议》明确提出"加快建设交通强国""构建现代化基础设施体系"，部里表示将重点支持……领域。这为我省交通运输发展提供了重大历史机遇。

#### （三）总体思路与主要目标

**写什么**：1 句指导思想 + 3-4 条基本原则 + 关键指标表 + 3 条选取原则

**总体思路句式**：

```
以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大和二十届二中、三中全会精神，深入贯彻习近平总书记关于交通运输工作的重要论述精神，按照党中央、国务院和省委、省政府决策部署……
```

**基本原则**（3-4 条短句排比）：

```
——服务大局，战略引领。
——深化改革，创新驱动。
——统筹协调，重点突破。
——绿色低碳，安全韧性。
```

**指标表关键数字突出**（加粗）：

| 类别 | 指标 | 2025 年 | 2030 年 | 2035 年 |
|---|---|---|---|---|
| 规模 | 铁路营业里程（公里） | 3500 | **4200** | **5000** |
| 规模 | 高速公路里程（公里） | 5500 | **6000** | **6800** |
| 效率 | 综合客运枢纽转换时间（分钟） | 30 | **20** | **15** |
| 覆盖 | "四好农村路"通达率（%） | 95 | **98** | **100** |
| 投资 | 五年累计投资（亿元） | — | **20000** | — |

> **数据加粗规则**：所有 2030 年/2035 年关键数字**必须加粗**，领导汇报场景下这些数字是后续提问与决策的锚点。

**指标选取三原则**（说明类，必须有）：

```
——体现国家战略导向，对标交通强国建设目标。
——立足我省发展阶段，反映"十四五"基础与"十五五"目标衔接。
——聚焦关键领域短板，突出对高质量发展的支撑引领作用。
```

#### （四）主要任务

**写什么**：5-8 项重点任务，每项"一句话定位 + 若干要点"

**每条任务结构**：

```
任务 N：[一句话定位]

[政策依据引用]——"党中央《建议》强调：……""省委《建议》要求：……"

要点 1：……
要点 2：……
要点 3：……
主要目标：[大数字加粗]
```

**示例（任务 1，约 200 字）**：

> 任务 1：加快建设世界一流强港，引领港口高质量发展。
> 党中央《建议》强调："加快建设世界一流港口"。省委《建议》要求："支持宁波舟山港打造世界一流强港"。部里表示将继续给予政策支持。
> 一是优化港口功能布局。推进宁波舟山港与上海港、东南亚港口错位发展，重点发展集装箱干线港。
> 二是提升港口集疏运能力。规划建设"××铁路""××高速"等集疏运通道，形成"公铁水"多式联运体系。
> 三是打造港口智慧绿色标杆。建成智慧港口示范工程 **3** 个、绿色低碳港区 **5** 个。
> 主要目标：到 2030 年，宁波舟山港货物吞吐量达 **13 亿吨**、集装箱吞吐量达 **4200 万标箱**。

#### （五）拟纳规项目

**写什么**：项目上报情况 + 纳规原则 + 投资概况 + 重大工程谋划

**1. 项目上报情况**（数据 + 来源）：

```
项目上报情况：本次规划编制共收到各地、各部门上报项目 XXX 个，总投资 XXX 亿元。
其中：交通基础设施项目 XXX 个，总投资 XXX 亿元；枢纽场站项目 XXX 个，总投资 XXX 亿元。
```

**2. 纳规总体原则（量化评分规则）**：

```
纳规总体原则：依据"战略导向、必要可行、量力而行、效益优先"四项原则，按以下量化指标评分：
——战略匹配度（30 分）：是否符合上位规划与省级战略
——建设必要性（25 分）：是否解决瓶颈短板
——技术可行性（20 分）：技术标准与方案是否成熟
——投资合理性（15 分）：投资规模与地方承受能力
——综合效益（10 分）：经济效益、社会效益、生态效益
总分 ≥ 75 分纳入规划；60-74 分纳入储备；< 60 分不纳入。
```

**3. 拟纳规项目和投资概况**（表格）：

| 类别 | 项目数（个） | 投资（亿元） | 占比（%） |
|---|---|---|---|
| 铁路 | **45** | **8500** | 42.5 |
| 公路 | **62** | **6200** | 31.0 |
| 水运 | **28** | **2500** | 12.5 |
| 航空 | **8** | **1500** | 7.5 |
| 枢纽 | **15** | **1300** | 6.5 |
| **合计** | **158** | **20000** | 100 |

**4. 重大工程谋划**（每个工程单页 PPT，文字稿用统一段落模板）：


## 七、常见错误与规避

### 7.1 结构层错误

| 错误类型 | 表现 | 规避方法 |
|---|---|---|
| 主次颠倒 | 前期工作进展写 5 页，主要内容只写 3 页 | 严格按 60-65% 主体比重分配 |
| 缺主动问题 | 没有"重点问题说明"，领导追问难接 | 必含 3-5 个主动问题 |
| 缺请求支持 | 没有"需上级支持事项"，汇报无落点 | 必含 3-5 条具体支持事项 |
| 时间线模糊 | "近期""前段时间"等模糊表达 | 精确到年月的标志节点句 |
| 成绩问题失衡 | 只讲成绩不点问题 | 必含 3-5 项短板 |

### 7.2 数据层错误

| 错误类型 | 表现 | 规避方法 |
|---|---|---|
| 关键数字未加粗 | 2030 年目标数字与正文混排 | 关键数字统一加粗 |
| 单位遗漏 | "投资 1452"缺"亿元" | 全文数字+单位一体 |
| 时间口径混乱 | "十四五"与"第 14 个五年规划"混用 | 统一用"十四五""十五五"加引号 |
| 数字不一致 | 文字稿 2 万亿、PPT 1.8 万亿 | 文字稿与 PPT 同源数据校验 |
| 范围连接符错误 | "2021～2035 年"使用波浪号 | 改用半角连字符"2021-2035 年" |

### 7.3 文字层错误

| 错误类型 | 表现 | 规避方法 |
|---|---|---|
| 排比句散文化 | "一是大…二是大…三大"结构混乱 | 严格"一是…二是…三是…" |
| 政策引用不规范 | "中央说""上面要求"等口语化 | 用"党中央《建议》强调""省委《建议》要求" |
| 段首不缩进 | 全角空格代替缩进 | 严格首行缩进 32pt |
| 中英文标点混用 | 英文逗号", "出现在中文段 | 全文使用中文全角标点 |
| 句子过长 | 单段超 200 字 | 单段控制在 100-150 字 |

### 7.4 汇报现场雷区

| 雷区 | 后果 | 规避 |
|---|---|---|
| 数据有水分被当场识破 | 汇报失效 | 所有数据均可追溯到出处 |
| 时间节点对不上 | 失信于领导 | 时间线交叉核对 |
| 答非所问 | 领导不满 | 重点问题主动说透 |
| 读稿子式汇报 | 听众疲倦 | 多用排比、强调数字 |
| 一味报喜 | 显得不诚实 | 主动点出 3-5 项短板 |

## 九、附录：常用过渡词与句式

### 9.1 段落起始过渡词

- "总体来看……""综合判断……""当前……""与此同时……"
- "与此同时，也要清醒看到……""更需关注的是……"
- "在此背景下……""面对新形势新要求……"

### 9.2 排比句式

- "一是…二是…三是…四是…五是…"（成绩/任务列举）
- "——……；——……；——……；——……。"（基本原则/特点）
- "从历史发展看…从发展需要看…从中央要求看…"（形势分析）

### 9.3 结论性句式

- "综上，规划期内……"
- "据此，我们建议……"
- "经测算，预计……"
- "对照目标，差距主要在……"
- "下一步，重点推进……"

### 9.4 致谢/结尾

- "汇报完毕，请各位领导批评指正。"
- "以上汇报，不当之处敬请指正。"
- "恳请各位领导提出宝贵意见。"
