# 07 交通影响评价报告（交评）模板

## 一、文档定位与适用场景

**用途**：建设项目（工业基地、住宅地块、商业综合体、交通枢纽、市政设施）报建前，评估项目建成后对周边路网交通的影响，提出内部设施与外部交通组织改善建议。报告结论直接影响规划许可。

**适用对象**：自然资源和规划局（审批）、建设单位、设计单位。
**案例出处**：浙江金属真空镀膜制造基地项目交通影响评价（成果稿）、余政储出【2021】5号地块项目交通影响评价（报建）、温州南陆港枢纽工程（动车所上盖开发）交通影响评价、飞龙湖区块城市停车场建设项目交通影响评价（城规所/交通影响评价/）。

**篇幅**：50-80 页（含图集）。**特色**：结论前置——报告最前面放"一、技术指标评价 / 二、相关建议"摘要，决策者 2 分钟读完。

## 二、结构骨架

```
一、技术指标评价 ✅（结论前置）
    （对照表：评价类别 | 评价指标 | 规范要求指标 | 设计方案指标 | 评价结论）
二、相关建议 ✅（摘要式）

第一章 项目概况 ✅
    1.1 项目背景
    1.2 建筑设计方案（总平面、主要功能、建筑面积、停车配建）
    1.3 评价范围与年限（评价范围图；建设期、近期、远期）
    1.4 评价重点与技术路线
    1.5 评价依据（法律法规/技术规范/项目资料）
第二章 现状及规划分析 ✅
    2.1 土地利用现状
    2.2 道路网络现状（道路等级、断面、通行能力）
    2.3 交通运行现状（高峰小时流量、饱和度、服务水平）
    2.4 公共交通现状（公交线路、站点、轨道）
    2.5 规划路网情况（上位规划路网、建设时序）
第三章 内部设施评价 ✅（逐项对照规范）
    3.1 基地出入口评价（位置、数量、间距、视距）
    3.2 地库出入口评价
    3.3 非机动车库出入口评价
    3.4 通道宽度与转弯半径评价
    3.5 停车视距与车库净高评价
    3.6 配建泊位指标评价（车位/百㎡ 对照规范）
    3.7 机动车泊位评价（数量、尺寸、无障碍、充电、装卸车位）
第四章 交通组织改善建议 ✅
    4.1 道路网络及交通管控建议（信号、禁左、单行、标线）
    4.2 小型车交通组织流线建议（到达 / 驶离）
    4.3 货车交通组织流线建议（到达 / 驶离）
第五章 交通影响分析 ✅
    5.1 需求预测思路（预测方法、参数）
    5.2 背景交通需求（无项目路网需求）
    5.3 项目交通需求（生成、分布、方式划分）
    5.4 交通影响分析（叠加后路段/交叉口饱和度、服务水平、影响程度）
```

**项目类型差异**（四案例对比）：
- 工业基地（镀膜基地）：重货车流线、厂区出入口
- 住宅地块（余政储出5号地块）：重早晚通勤高峰、地库出入口、学校/幼儿园接送
- 枢纽上盖（温州南陆港动车所上盖）：重综合交通集散、多方式接驳、施工期交通
- 市政设施（飞龙湖停车场）：重公共停车需求、节假日高峰

## 四、逐章写作要点

### 前置结论（一、技术指标评价 / 二、相关建议）
- **技术指标评价表**：按评价类别分组（通道宽度、转弯半径、泊位、出入口…），每行 = 指标 + 规范要求 + 设计方案指标 + 评价结论（"满足"/"基本满足，建议…"）
- **相关建议**：3-5 条，每条一句话，按优先级排序（"建议1：…"）
- 规范要求列必须精确引用条款（如"小型车双向通行通道宽度大于等于6m，单向通行大于等于5m；消防车双向通行通道宽度大于等于4m"）

### 第一章 项目概况
- **1.2 建筑设计方案**：总平面图、功能分区、建筑面积指标表、停车位布置（含无障碍/充电/装卸车位）
- **1.3 评价范围与年限**：评价范围 = 项目周边 2-3 个路口/路段范围，附范围图；年限 = 建成年 + 建成后5-10年
- **1.5 评价依据**：四层结构（法规→规范→标准→项目资料），规范必须最新版

### 第二章 现状及规划分析
- **2.2 道路网络**：道路一览表（名称/等级/红线宽度/断面形式/通行能力）
- **2.3 交通运行**：高峰小时流量调查表、交叉口饱和度与服务水平评价（LOS A-F）
- **2.5 规划路网**：上位规划与本项目的关系，规划道路建设时序

### 第三章 内部设施评价（报告主体，逐项"规范—方案—结论"）
每小节统一结构：
```
【规范要求】引用规范条款（含条款号）
【设计方案】本项目实际指标
【评价结论】满足 / 基本满足+整改建议 / 不满足+整改建议（附示意图）
```
- **3.1 出入口**：位置是否与交叉口冲突（距交叉口停车线距离）、数量与交通需求匹配、进出口道宽度、视距三角形
- **3.4 通道宽度**：地面/地库分开评价（地库"尽端式通道长度大于26m时应满足回车条件"）
- **3.6 配建泊位**：对照当地停车配建标准（X 车位/百㎡ 商业），给"规范要求 vs 设计配建"表
- **3.7 泊位**：普通车位/无障碍车位/充电车位/装卸车位分项核对

### 第四章 交通组织改善建议
- 按"路网管控 / 小型车 / 货车"分类；小型车和货车再分"到达-驶离"两条流线，各配流线示意图
- 建议可执行：信号配时调整、禁左、单行组织、出入口改造、标线优化

### 第五章 交通影响分析
- **5.2 背景交通**：趋势外推（历年流量增长率）或规划模型
- **5.3 项目交通**：出行生成率（依据规范/类比项目）→ 高峰小时系数 → 方式划分 → 方向分配
- **5.4 影响分析**：项目交通叠加背景交通，评价交叉口/路段服务水平变化；判定影响程度（显著影响→需改进措施）；附"有项目/无项目"对比表

## 五、句式与表格模板

```
【结论表模板】
| 评价类别 | 评价指标 | 规范要求指标 | 设计方案指标 | 评价结论 |
| 通道宽度 | 地面小型车通道 | 双向≥6m，单向≥5m | 5-10m | 满足双向/单向通行条件 |
| 停车视距 | 出入口视距 | ≥Xm | Xm | 满足 |

【评价结论句式】
"经核查，基地内部小型车通道宽度5-10m，轻型车行驶通道宽度6-10m，满足小型车、轻型车双向/单向通行条件，消防车通道宽度4m满足规范要求。"

【建议句式】
"建议将基地出入口调整为右进右出组织，禁止左转，减少对主干路交通的干扰。"
```

## 六、图表规范

- 图：区位图、评价范围图、总平面图、现状路网图、流量图（高峰小时）、流线组织图（到达/驶离）、效果示意图——编号 图X-Y
- 表：建筑指标表、现状道路一览表、流量调查表、服务水平评价表、泊位对照表、影响对比表——编号 表X-Y
- 图集：出版版附单独图集册（扉页+正文图+图集）

## 七、常见错误与规避

1. **规范引用过期/无条款号**：评价依据必须精确到条款，专家逐条核对
2. **结论含糊**：每个指标必须给出"满足/不满足"明确结论，不能用"建议进一步优化"搪塞
3. **漏货车流线**：工业/物流项目货车流线是必查项，要单独成节
4. **背景交通口径不清**：背景交通量要注明基年、增长率来源、预测年
5. **前置结论与正文不一致**：摘要页数据必须与正文逐条一致
6. **无整改闭环**：第三章评价出的"不满足"项，第四章必须有对应整改建议
