# 10 规划研究类报告模板（评估研究、专题研究）

## 一、文档定位与适用场景

**用途**：数字化转型升级研究、政策评估、专题调查、规划实施评估等"研究型"成果。与规划/可研不同：研究类报告以**评估现状 → 借鉴经验 → 提出方案**为逻辑主线，结论开放，重在论证过程。

**适用对象**：委托部门（省厅/市局）、评审专家组、决策层。
**案例出处**：1128 数字化2.0研究报告（评审稿）、公路沿线充电设施调查、慈溪市交通物流体系发展规划研究（含评审意见修改说明）。

**篇幅**：60-150 页（评审稿）；调查类 30-80 页。

## 二、结构骨架

```
一、研究概述 ✅
    1、研究背景与内容
    2、技术路线（研究框架图：现状评估→经验借鉴→方案研究）
二、现状评估分析 ✅
    1、上一阶段方案回顾（"1.0"方案回顾：目标—内容—实施—成效）
    2、年度工作进展（分领域进展+数据）
三、案例分析和经验借鉴 ✅
    1、案例逐个分析（江苏省、上海市…；每个案例：做法—成效—启示）
    2、经验启示提炼（4条左右：融合前沿技术/聚焦核心场景/提升服务体验/健全协同机制）
四、总体方案研究 ✅
    1、政策解读（政策文件梳理与要求提炼）
    2、发展需求（需求分析）
    3、总体思路（指导思想+基本原则）
    4、发展目标（总体目标+分项目标+指标体系）
    5、方案内容（1、推广场景 2、新增场景…）
五、措施和建议 ✅
    （政策/资金/机制/技术四方面，分条建议）
```

**调查类变体**（公路沿线充电设施调查）：
```
一、调查背景与目的 → 二、调查方案（范围、方法、样本）→ 三、调查结果统计（分区域/分类型）
→ 四、问题分析 → 五、对策建议
```

## 三、格式规范（实测：数字化2.0 docx）

| 元素 | 字体 | 字号 |
|---|---|---|
| 封面标题 | 方正小标宋简体 | 22pt |
| 封面单位/日期 | 楷体_GB2312 | 16pt |
| 前言 | 黑体 | 16pt |
| 一级标题（一、研究概述） | 黑体 | 16pt |
| 二级标题（（一）研究背景） | 楷体_GB2312 | 16pt 加粗 |
| 三级标题（1、研究内容） | 仿宋_GB2312 | 16pt |
| 正文 | 仿宋_GB2312 | 16pt |
| 图题 | Caption样式（Times New Roman 加粗） | 同正文 |
| 行距 | 1.5倍 或 固定29磅 | 首行缩进32pt |

编号体系：一、→（一）→1、→（1）（研究类用"1、"不用"1."，与可研区分）

## 四、逐章写作要点

### 一、研究概述
- **研究背景**：宏观政策（"国家已经全面进入统筹高质量发展和高水平安全的新阶段…"）→ 行业要求 → 委托需求
- **研究内容**：3-5 项，用"首先是…然后…最后…"衔接（"首先是分析…初步成效；然后提出…布局方案；最后…"）
- **技术路线**：框架图（研究阶段—研究内容—成果产出），评审专家第一眼看这个

### 二、现状评估分析
- **方案回顾**：上一版方案的目标、内容、实施情况、取得成效——数据说话（覆盖里程、应用数量、投资完成率）
- **年度进展**：分领域逐项（基础设施/平台/应用/机制），每项"做了什么+数据+问题"

### 三、案例分析和经验借鉴（研究类特色章）
- **案例选择**：3-5 个，覆盖先进省份/同级对标/国际经验；每个案例结构统一：基本情况→主要做法→实施成效→经验启示
- **启示提炼**：跨案例归纳 4 条左右，每条 = 主题词 + 展开（"1、融合前沿技术——…；2、聚焦核心场景——…；3、提升服务体验——…；4、健全协同机制——…"）
- 忌：案例堆砌无提炼——启示章是全章价值所在

### 四、总体方案研究
- **政策解读**：梳理政策文件清单（表格式：文件名+文号+核心要求），提炼对本地要求
- **发展需求**：从政策要求、现状问题、用户需求三个来源推导
- **总体思路**：指导思想（以…为指导…）+ 原则
- **发展目标**：总体目标一句话 + 分项目标 + 指标表（指标/现状/目标/属性）
- **方案内容**：按"推广场景/新增场景"分类（延续性工作 vs 创新性工作），每个场景 = 场景描述+建设内容+实施路径

### 五、措施和建议
- 四维度：政策（法规标准）、资金（投入机制）、机制（协同/考核）、技术（攻关/数据）
- 每条建议 = 建议事项 + 具体做法 + 责任主体建议；3-5 条/维度
- 评审稿建议后附"下步工作计划"（时间表）

## 五、评审配套（评审稿专用）

### 评审意见修改说明表（慈溪案例实测格式）
```
评审意见修改说明
序号 | 专家建议 | 修改反馈 | 详见页码
1   | 第一章概述中增加研究范围、规划年限、研究依据等 | 已修改，已补充研究范围、规划年限和研究依据，详见P4- | P4-
```
- 置报告最前（或单独成文）
- 每条意见必须闭环：修改了→给页码；不同意→说明理由

### 送审前自查清单
1. 研究范围/规划年限/研究依据是否齐全（专家高频意见）
2. 数据口径、基年是否注明
3. 图编号、表编号连续
4. 结论与摘要一致

## 六、句式库（实测原文）

```
【研究背景】总体来看，国家已经全面进入统筹高质量发展和高水平安全的新阶段，行业…（宏观判断）
【研究内容衔接】首先是分析全省公路水路基本运行情况及示范数字化转型升级初步成效…
然后提出全省公路水路数字化转型升级2.0布局方案…（首先/然后/最后）
【经验启示】先进技术的融合应用和深度集成是数字化转型的核心动力，前沿技术和交通…（提炼句）
【方案表述】按照一体化任务全部实施、示范性任务按需规模化建设的原则，围绕…（原则+内容）
```

## 七、常见错误与规避

1. **案例只述不评**：每个案例必须有"启示"，且启示要收敛到 4 条以内
2. **现状评估无数据**：评估结论必须配指标数据，不能定性空转
3. **方案与需求脱节**：总体方案每项内容要能追溯到政策解读或需求分析
4. **政策解读罗列文件不提炼**：政策清单后必须有"对本地要求"的提炼段
5. **建议不可执行**：每条建议给出责任主体和实施路径
6. **技术路线与实际内容不符**：框架图与研究内容必须一一对应（专家必查）
