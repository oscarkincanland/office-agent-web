# 11_PPT汇报模板（详版）

> 数据基础：00_格式数据汇总.md 第六部分（PPT 四类场景实测：汇报47页 / 解读80页 / 研讨演讲22页 / 培训102页）
> 适用场景：规划汇报、专题汇报、工作汇报、解读宣讲、研讨演讲、培训授课
> 核心目标：从四类 PPT 实测中蒸馏通用汇报 PPT 制作规范

---

## 一、文档定位与适用场景

### 1.1 写给谁

- **汇报类 PPT**：听汇报的上级领导（省长/厅长/部长）、会议主席台成员
- **解读类 PPT**：各级干部、相关部门同志、行业系统人员（集体学习）
- **研讨演讲类 PPT**：行业专家、智库学者、研讨会议参与者
- **培训授课类 PPT**：培训学员、行业从业者、新入职干部

### 1.2 什么时候用

| PPT 类型 | 触发场景 | 页数范围 | 节奏控制 |
|---|---|---|---|
| 汇报类 | 领导汇报、专题汇报 | 20-50 页 | 8-12 分钟/页 |
| 解读类 | 规划解读、文件解读 | 60-100 页 | 3-5 分钟/页 |
| 研讨演讲类 | 学术研讨、专家演讲 | 15-30 页 | 4-6 分钟/页 |
| 培训授课类 | 专题培训、岗位培训 | 80-150 页 | 2-3 分钟/页 |

### 1.3 与文字稿的关系

- **汇报类**：PPT 是文字稿的口述提纲，每页附 200-400 字口述稿（参考 08_汇报材料模板）
- **解读类**：PPT 自成体系，文字稿为可选项
- **研讨演讲类**：PPT 是演讲骨架，文字稿为概念性提示
- **培训授课类**：PPT 是讲义主体，文字稿转化为讲师手册

## 二、PPT 四类场景实测骨架（蒸馏基础）

### 2.1 A. 规划汇报 PPT（47 页，省"十五五"汇报）

骨架：P1 封面 → P2 目录（1进展/2内容/3问题/4计划）→ P3 进展页（5 阶段时间线）→ P4 章节过渡页（大字"02"）→ P5-7 发展基础（成就+问题）→ P9 形势页（三个看）→ P11 总体思路（"3""4""5"数字可视化）→ P12-13 目标页（指标表+原则）→ P15 任务总览（8大任务/14大专项）→ P16-24 每任务1页（政策引用+要点+大数字）→ P25 标志性成果（01-05 编号）→ P27-30 拟纳规项目（上报/原则/投资/分类）→ P31-39 每重大工程1页（5要素模板）→ P41-44 重点问题（三个看+资金来源）→ P46 下步计划（一是…二是…）→ P47 汇报完毕。

### 2.2 B. 规划解读 PPT（80 页）

骨架：封面 → 目录（编制背景/特点框架/主要内容）→ 每节前章节过渡页（重复目录+高亮当前节）→ 政策层解读（国家规划→省纲要→交通专项）→ 成就页（大数字+图标）→ "123510"式核心内容提炼（1目标、2万亿投资…）→ 规划特点页（编号+主题+解释）→ 总体框架（环境/要求/任务/保障）。

### 2.3 C. 研讨演讲 PPT（22 页）

骨架：P1 封面（标题+单位+发言人+日期）→ P2 开篇引用（习总书记赋予…使命）→ P3 三部分目录（01/02/03 编号）→ P4/11/17 部分过渡页（大字）→ 正文页（论点句标题+论据）→ P18 问题页（01 如何…？02 如何…？03 如何…？）→ P22 谢谢。

### 2.4 D. 培训授课 PPT（102 页）

骨架：P1 封面（主标题+副标题+报告人+时间）→ P2 目录 CONTENTS → P3 章节页（章节号+章节名+本节要点）→ 正文页（概念定义页/演进对比页/理论引用页）→ 每页结构（观点句标题+图解+表格）。

### 2.5 四类 PPT 共性与差异

| 维度 | 汇报类 | 解读类 | 研讨演讲类 | 培训授课类 |
|---|---|---|---|---|
| 页数 | 20-50 | 60-100 | 15-30 | 80-150 |
| 信息密度 | 中 | 中高 | 低 | 高 |
| 文字/图表比 | 6:4 | 5:5 | 4:6 | 5:5 |
| 章节过渡页 | 必备 | 必备 | 部分 | 部分 |
| 结尾页 | "汇报完毕" | "敬请指正" | "谢谢" | "答疑环节" |

## 三、PPT 通用规范（10 条蒸馏）

### 3.1 规范 ①：封面四要素

```
┌─────────────────────────────┐
│     [主标题 — 大字]            │
│     [副标题（可选）]           │
│     [汇报单位 / 发言人]        │
│     [日期（汉字）]              │
└─────────────────────────────┘
```

四要素齐全：主标题、副标题（可选）、单位/发言人、日期（汉字"二〇二六年一月"）。

### 3.2 规范 ②：目录 3-4 部分

汇报类用"1 2 3 4"数字列表，演讲类用"01 02 03"双零编号。每项一句话说明（≤25 字）。培训类底部加"CONTENTS"英文小字。

### 3.3 规范 ③：章节过渡页（汇报 PPT 必备）

```
┌─────────────────────────────┐
│         02                  │  ← 大字章节号（120-160pt）
│    规划主要内容              │  ← 章节名（36-40pt）
│  （一）发展基础              │
│  （二）发展形势              │  ← 小节导航（18-22pt）
│  （三）总体思路与主要目标    │
└─────────────────────────────┘
```

章节号独占视觉重心，章节名黑体，当前小节加粗高亮。

### 3.4 规范 ④：正文页信息结构

```
┌─────────────────────────────┐
│ 章节名·任务名                │  ← 顶部标题条（22-28pt）
├─────────────────────────────┤
│   [要点文字]                  │
│   [图表]                      │  ← 内容区
│   [大数字块]                  │
└─────────────────────────────┘
```

- 标题条：底部 1-2pt 横线分隔
- 内容区分为 3 列网格（左文字 / 中图表 / 右数字）
- 单页信息量：**标题≤20 字、正文≤6 行/页**

### 3.5 规范 ⑤：政策引用句式

固定句式库（背诵级）：

```
——"党中央《建议》强调：……"
——"省委《建议》要求：……"
——"部里表示：……"
——"国家《纲要》明确：……"
```

政策引用使用单独色块（深蓝/深红），引文加粗或反白，左侧 4pt 竖线标识"政策依据"。

### 3.6 规范 ⑥：大数字可视化

独立大字块形式：

```
┌─────────────┐
│   6800      │  ← 数字（72-96pt，加粗）
│   公里       │  ← 单位（22-28pt）
│ 高速公路里程  │  ← 说明（16-18pt）
└─────────────┘
```

常见类型：里程类（6800 公里）、人次类（1.3 亿人次）、投资类（2 万亿元）、数量类（超 270 条）、增长率类（35%）。

### 3.7 规范 ⑦：统一模板页（重大工程页 5 要素）

```
┌─────────────────────────────┐
│ 重大工程 N：工程名称          │
├──────────┬──────────────────┤
│  [图片]   │ 建设意义：……     │
│          │ 项目数量：XX 个   │
│          │ 项目投资：XX 亿元 │
├──────────┴──────────────────┤
│ 主要项目表（图或表）           │
└─────────────────────────────┘
```

5 要素：建设意义（25%）+项目数量（10%）+项目投资（10%）+工程图片（30%）+主要项目（25%）。汇报 PPT 中所有重大工程页保持版式统一。

### 3.8 规范 ⑧：观点句式

**三段式（从 X 看）**：

```
从历史发展看，……  （回顾成绩/历史方位）
从发展需要看，……  （现实需求）
从中央要求看，……  （政策导向）
```

**提问式（研讨演讲类）**：

```
01 如何提高投资绩效？
02 如何提升运输效能？
03 如何更好服务共富？
```

**标志性成果式**：

```
01 世界一流强港
02 轨道上的浙江
03 区域一体化交通
04 "四好农村路"标杆
```

### 3.9 规范 ⑨：结尾页

| PPT 类型 | 结尾页内容 | 版式 |
|---|---|---|
| 汇报类 | "汇报完毕，请各位领导批评指正" | 居中大字 40-60pt |
| 解读类 | "敬请批评指正"+宣讲人/单位/日期 | 居中大字 40-60pt |
| 研讨演讲类 | "谢谢" | 居中大字 100-160pt |
| 培训授课类 | "答疑环节"+联系方式 | 居中大字 40-60pt |

### 3.10 规范 ⑩：每页信息量控制

| 元素 | 数量上限 | 字号下限 |
|---|---|---|
| 页面标题 | ≤20 字 | 24-40pt |
| 正文要点 | ≤6 行 | 18pt |
| 单行字数 | ≤30 字 | — |
| 关键数字 | 3-5 个/页 | 36-96pt |
| 图表数量 | 1-2 个/页 | — |

## 四、字号与字体规范

### 4.1 字号下限（PPT 通用）

| 元素 | 字号下限 | 说明 |
|---|---|---|
| 封面主标题 | 36pt | 远距离可读 |
| 封面副标题 | 22pt | — |
| 章节过渡页大字 | 120pt | 章节号 |
| 章节过渡页章节名 | 36pt | — |

| 正文要点 | **18pt** | 必备下限 |
| 表格内容 | 14pt | 表格密集可适当 |
| 图注 | 10-12pt | — |

## 六、逐页写法详解

### 6.1 封面/目录/过渡页（P1-P3、P5、P24、P27）

**P1 封面**：左侧 1/3 项目区位图或效果图作底图，主标题（方正小标宋/思源宋体 Heavy 44pt 居中），副标题可选（楷体 22pt 居中），落款黑体/楷体 18pt，日期汉字"二〇二六年一月"。要点：标题优先，底图不喧宾夺主。

**P2 目录**：顶部英文"CONTENTS"小字，4 部分数字列表"1 2 3 4"（汇报类）或"01 02 03"（演讲类），每项一句话说明（≤25 字）。

**章节过渡页**（P3/P5/P24/P27）：大字章节号"02"（120-160pt 居中）+ 章节名"规划主要内容"（36-40pt）+ 小节导航（18-22pt，当前小节加粗高亮）。要点：章节号独占视觉重心，节奏放缓。

### 6.2 时间线页（P4）

横向时间轴 5 节点等距分布，每节点下方 1 段话（80-150 字）。时间精确到月（不要"近期""前段时间"）。

```
2023.6        2023.7-10      2023.11-2024.6    2024.7-9    2024.10
  |              |                |               |            |
启动部署     调研起草         规划编写        征求意见      评审修改
```

### 6.3 现状-成就/问题页（P6/P7）

**成就页**：编号 01-05，每条主题+破折号+数据，关键数字 24-32pt 加粗。示例：

```
01 有力支撑经济回升向好
   ——综合交通投资 1.45 万亿元，年均增长 8.5%
02 综合交通网络更加完善
   ——铁路/公路/水运/航空里程分别达 ×/×/×/×
```

**问题页**：编号与成就页呼应，3-5 条短板描述具体，配短板雷达图/柱状图。

### 6.4 形势页（P8/P9）

"三个看"三段式分布：左栏从历史发展看（简短回顾）、中栏从发展需要看（现实需求 1-2 段）、右栏从中央要求看（政策导向，引用《建议》）。底部配合"机遇地图"或"战略路径图"。中央要求用政策引用色块突出。

### 6.5 总体思路页（P10）

顶部"3 个转变 / 4 个方向 / 5 个突破"数字矩阵；中部四象限图（战略引领/改革创新/绿色低碳/安全韧性）；底部核心理念排比（——服务新发展格局；——推动高质量发展；——满足人民美好出行）。

### 6.6 目标页（P11/P12）

**P11 指标表**：表格+大数字块组合，2030/2035 关键数字加粗，属性列（预期性/约束性）必备。

```
类别 | 指标 | 2025年 | 2030年 | 2035年 | 属性
规模 | 铁路营业里程（公里） | 3500 | 4200 | 5000 | 预期性
规模 | 高速公路里程（公里） | 5500 | 6000 | 6800 | 预期性
效率 | 综合客运枢纽转换时间（分钟） | 30 | 20 | 15 | 约束性
```

**P12 选取原则**：三条排比——"体现国家战略导向，对标交通强国建设目标。""立足我省发展阶段，反映'十四五'基础与'十五五'目标衔接。""聚焦关键领域短板，突出对高质量发展的支撑引领作用。"

### 6.7 主要任务页（P14-P17）

每页结构：政策依据色块（深蓝/深红，左侧 4pt 竖线）+ 三要点（一是…二是…三是…）+ 右下大数字块。

```
[页面标题]任务 1：加快建设世界一流强港

[政策依据色块]
"党中央《建议》强调：加快建设世界一流港口"
"省委《建议》要求：支持宁波舟山港打造世界一流强港"
```

### 6.9 拟纳规项目页（P19/P20）

**P19 上报情况与纳规原则**：左侧数据（上报项目 XXX 个、总投资 XXX 亿元）+ 右侧评分规则表（战略匹配度 30 分、建设必要性 25 分、技术可行性 20 分、投资合理性 15 分、综合效益 10 分；总分 ≥75 纳入规划、60-74 储备、<60 不纳入）。

**P20 投资概况**：饼图（分领域投资构成）+ 柱图（分地区投资分布）+ 时序图（"十五五"逐年投资安排）三图组合。

### 6.10 重大工程页（P21-P23）

5 要素模板（详见 3.7 节规范⑦）：左图右文 1:1 布局，多页工程保持版式统一（汇报关键）。表头数据：项目名称/里程（公里）/投资（亿元）。

### 6.11 重点问题说明页（P25/P26）

**P25 投资规模**："三个看"三段式（从历史发展看——"十四五"投资 1.45 万亿元；从发展需要看——新增需求 1.8 万亿元；从中央要求看——国家鼓励补短板）+ 结论数字（2 万亿元）。

**P26 资金来源**：4 象限饼图（中央 6000 亿 30% / 省级 5000 亿 25% / 市县 4000 亿 20% / 社会 5000 亿 25%）。

### 6.12 下步计划/结尾页（P28/P29）

**P28 下步计划**："一是…（×月完成）二是…（×月完成）三是…（×月完成）"排比 + 底部请求支持事项（印发方案/建立机制/资金倾斜 3-5 条）。

**P29 结尾**：居中大字"汇报完毕"（100-160pt）+ 小字"请各位领导批评指正"+ 落款（单位+人+日期）。要点：不堆砌装饰元素，保持庄重。

## 七、图表规范

### 7.1 图表选用规则

| 数据特征 | 选用图表 | 适用页示例 |
|---|---|---|
| 时间序列 | 折线图、柱状图 | 投资规模历年变化 |
| 占比构成 | 饼图、环形图 | 投资来源构成 |
| 区域对比 | 横向柱状图 | 各市投资对比 |
| 多维对比 | 雷达图 | 短板诊断 |
| 流程关系 | 流程图、架构图 | 编制流程 |
| 空间分布 | 地图 | 项目分布 |
| 进展对比 | 进度条 | 各项指标完成率 |

### 7.2 图表设计要点与避坑

- **设计要点**：配色与 PPT 主色调一致；图表内文字 14-18pt；网格线浅灰 #F0F0F0；数据标签直接显示在图形上；图注 10-12pt 简注来源
- **避坑清单**：禁用 3D 饼图（改 2D 平面）；禁用彩虹配色（改主色调 3-5 色）；网格线改浅灰细线（禁粗黑）；图例贴近数据；字号最小 14pt；复杂多轴拆为多图

## 九、常见错误与规避

### 9.1 结构层错误

| 错误 | 表现 | 规避 |
|---|---|---|
| 章节过渡页缺失 | 章节之间没有停顿，节奏过快 | 汇报类必备章节过渡页 |
| 结尾页无落款 | "汇报完毕"后无单位/日期 | 加落款，庄重收尾 |
| 目录与正文不对应 | 目录写 4 部分，正文写 5 部分 | 严格一一对应 |
| 时间线只有起点终点 | 中间过程缺失 | 5 阶段完整呈现 |

### 9.2 字号层错误

| 错误 | 表现 | 规避 |
|---|---|---|
| 正文小于 18pt | 投影后看不清楚 | 严格 ≥18pt |
| 标题大于 44pt | 视觉喧宾夺主 | 标题 24-40pt |
| 字号过多层级 | 5 种以上字号 | 控制 3-4 种字号 |
| 数字字号过大 | 大数字块超 100pt | 大数字 72-96pt |

### 9.3 内容层错误

| 错误 | 表现 | 规避 |
|---|---|---|
| 单页信息过载 | 一页 8 个要点+3 个图表 | 严控 ≤6 行+1-2 图表 |
| 文字稿与 PPT 不同步 | 数字不一致 | 文字稿与 PPT 同源 |
| 政策引用不规范 | "中央说""上面要求" | 用"党中央《建议》强调" |
| 时间节点模糊 | "近期""前段时间" | 精确到月 |
| 缺大数字块 | 关键数字散落正文 | 重大数字独立大字块 |

### 9.4 美工层错误

| 错误 | 表现 | 规避 |
|---|---|---|
| 模板过于花哨 | 渐变/阴影/3D 滥用 | 简洁商务风 |
| 配色杂乱 | 一页 5 种以上颜色 | 严控主色+辅色+强调色 |
| 字体混用 | 一份 PPT 5 种字体 | 中英各 1-2 种 |
| 图标风格不统一 | 扁平+拟物混用 | 同一图标库 |
| 对齐错乱 | 元素参差不齐 | 严格网格对齐 |

### 9.5 汇报现场雷区

| 雷区 | 后果 | 规避 |
|---|---|---|
| 念 PPT | 听众疲倦 | 提纲式，讲稿口述 |
| 翻页过快 | 信息丢失 | 每页 8-12 分钟 |
| 翻页过慢 | 拖堂 | 严控时间 |
| 跳过过渡页 | 节奏断裂 | 过渡页正常展示 |
| 临时找不到页 | 现场慌乱 | 章节页标号清晰 |
| 数字临场算错 | 失信 | 数据预熟 |
