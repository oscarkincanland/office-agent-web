Agent 此前没有任何联网工具（Pi SDK 仅内置 bash/read/write 等本地工具），模型只能回答"没有联网搜索能力"。项目有写入沙箱（staging + 工作区边界 + Bash 路径防误操作），但没有网络层沙箱——搜索能力需要显式提供。

### 改动清单

| 文件 | 类型 | 改动内容 |
| --- | --- | --- |
| `server/联网搜索.mjs` | 新增 | 搜索后端抽象：Tavily（默认，免费 1000 次/月）/ SearXNG（自建，免费）/ Jina Reader（免 Key 可用）/ 博查（国内可达）；配置读写与脱敏（`.oaw/search.json`）、后端连通性测试、错误分类（超时/认证/配额/网络不可达给出可读提示） |

- `npm run test:search`：通过

### 使用方式

1. 设置 → 联网搜索 → 选择后端 → 填入 Key（Tavily 申请地址见界面提示）→ 测试连接 → 保存
2. 对 Agent 说"查一下 XX 最新政策"→ 自动调用 `web_search`，需要细读时 `web_fetch` 展开页面 → 回答带来源链接

### 开源/免费替代（对应 Tavily 额度之外的方案）

- **Jina Reader 搜索**（s.jina.ai，免 Key 有频率限制，零配置可用）
- **博查**（国内直连，注册有免费额度）
- Tavily 免费额度为 1000 次/月

## 阶段 B（内置浏览器）：browser_* 工具 + 可视化面板

### 实现方式

- 零依赖：Node 内置 WebSocket 直连 CDP；启动系统 Edge（headless=new）+ 独立 profile（保留登录态）
- 观察方式与 Playwright MCP 一致：可访问性语义快照（编号元素），非像素识别
- 画面：`Page.startScreencast` JPEG 帧 → `/api/browser/stream` SSE → 右侧“工作产物 → 浏览器”面板
- 接管：面板点击/输入/导航经 `/api/browser/input` 转发到页面（登录、验证码由用户完成）
- 工具：browser_open / snapshot / click / type / press / scroll / screenshot / back / close（仅 Agent 模式）
- 自动打开：浏览器会话激活时，前端自动切到“浏览器”页签（仅在激活瞬间触发一次）
- 搜索联动：`web_search` 未配置时提示改用内置浏览器；系统提示推荐 cn.bing.com 搜索（百度易触发人机验证）
- 韧性：PORT_FILE + `tryReuse()` 支持服务重启后复用仍存活的浏览器实例；复用失败自动清理空会话

### 关键修复（用户反馈：面板显示不了实时画面）

- **根因**：Agent 工具上下文中的 `clientId` 实际是复合 agentKey（`client::thread`），导致工具侧会话键为 `client::thread::thread`，与前端面板订阅的 `client::thread` 不一致 → 帧流推给了错误的键。
- **修复**：`browserSessionKey()` 归一化——当 clientId 以 `::thread` 结尾时剥离，工具与面板统一到同一键；并补充回归断言 + 真实链路帧流验证（面板键收到 `state.active` 与 19 帧画面）。
- 附带修复：`browserOpen` 先校验 URL 再启动（无效地址不再残留浏览器）；复用失败清理空会话；`OAW_BROWSER_PROFILE` 可自定义 profile 目录。

### 体验修复（用户反馈：黑屏 / 无法滑动接管 / Agent 自动关浏览器）

| 问题 | 处理 |
| --- | --- |
| 画面下方大片黑屏 | 根因是帧为横向（实测 1254×707），面板窄、图片按宽度缩放后高度小，下方露出容器纯黑背景。改为中性背景 + 垂直居中 + 图片阴影；帧事件补充真实尺寸元数据 |
| 无法滑动查看页面 | 新增滚轮接管：面板滚轮 → CDP `mouseWheel`（130ms 节流合并），页面可自由滚动；面板加提示行“滚轮滚动页面 · 点击接管操作” |
| 点击接管坐标不准 | 点击/滚轮坐标改为**归一化坐标**（0..1），服务端按实时布局视口换算，不受帧缩放/DPI/面板宽度影响 |
| Agent 自动关闭浏览器 | 三层保护：① 工具描述与系统提示改为“任务结束默认保留，仅用户明确要求才关闭”；② 服务端保护——用户 3 分钟内操作过则拒绝 Agent 关闭并提示保留；③ 面板关闭按钮为强制关闭（force） |
| 不影响 Agent 其他操作 | 浏览器为独立进程；用户接管输入为异步转发，不阻塞 Agent 工具链 |

### 二次体验修复（用户反馈：仍填不满 / 无法接管滑块验证码）

| 问题 | 根因与处理 |
| --- | --- |
| 仍显示旧界面（无新提示行、黑底） | 页面未硬刷新，浏览器仍在运行旧 JS bundle；`index.html` 已设 `no-store`，前端构建已含新面板（产物核对确认）。操作要求：**Ctrl+Shift+R 强制刷新** |
| 无法接管（关键） | 用户遇到的是**滑块验证码**，需要“按住拖动”；面板此前只支持单击（按下与抬起同点）→ 新增 `pointer` 动作（down/move/up），面板按住拖动即转发为 CDP 鼠标按压/移动/释放，支持滑块、画布、文本选择；40ms 节流防刷屏 |

### 三轮修复（产物打不开 / 标签页）

| 问题 | 根因与处理 |
| --- | --- |
| 产物打不开（404 not found） | 全局工作区为 `E:\...义乌十五五物流`，而产物属于 `F:\龙港数据`；`/api/doc` 只按全局工作区解析。修复：① 前端打开产物携带产物所属 `run.cwd`（并默认使用当前 UI 工作区）；② 服务端 `/api/doc`（含 raw/html）接受 `cwd` 查询参数，经 `normalizeWorkspace` 校验后按该工作区解析，且把 cwd 带入返回的子资源 URL。实测：不带 cwd 404 → 带 cwd 200 |
| 浏览器希望像 Chrome 有标签页 | 新增多标签能力：服务端 `fetchTargets/refreshTabs/newTab/switchToTarget/closeTab/reload`（CDP `/json/*` + 重连页面级 WebSocket + 帧流自动切换）；SSE 新增 `tabs` 事件；面板新增 Chrome 风格标签栏（点击切换、✕ 关闭、＋ 新建），工具栏新增刷新按钮；Agent 新增 `browser_tabs` 工具（list/new/switch/close）；系统提示补充多标签使用说明 |

## 四轮修复（预览回归 / 刷新性能 / 浏览器独立侧栏 / 接管失效）

| 问题 | 根因与处理 |
| --- | --- |
| 文件预览打不开（回归） | `open(name, thread, cwd)` 签名改造后，产物面板调用 `onOpenFile(path, run.cwd)` 把工作区传到了 thread 参数位 → 服务端按全局工作区解析 404。修复：调用改为 `(path, undefined, run.cwd)`，`open()` 内做 thread/cwd 兜底；实测跨工作区产物可打开 |
| 刷新加载慢（启动卡住） | ① 主包 2.5MB（katex/highlight/docx 全在首屏）：改造为**懒加载** —— MarkdownBody 的重型 rehype 插件动态加载、DocViewer 整体 React.lazy，主包降至 963KB（-61%），重库拆成按需 chunk；② 服务重启后首次 `/api/sessions` 需全量解析 247 个 JSONL（实测 15s）：改为**头部有界扫描（512KB）+ 元数据持久化缓存**（`.oaw/sessions-meta.json`），重启后首次 302ms；③ `/api/runs` 默认只带「运行中 + 最新 1 条」的尾部事件（按 160KB 字节预算裁剪），3.7MB → ~0.7MB；④ SSE 首次连接只回放最近 300 条事件（聊天正文由会话 JSONL 恢复） |
| 浏览器要独立侧栏（可伸缩） | 从「工作产物页签」中移出，改为**独立右侧栏**：独立 Resizer（`--browser-w`，340-960px）、顶栏地球按钮开关、Agent 活动时自动展开、全屏模式改为铺满该侧栏；未启动时提供地址栏 + 快捷链接（必应/百度/示例页），用户可像 Chrome 一样独立使用（新增 `POST /api/browser/open`） |
| 点不了浏览器 / 输入不了文字 | 关键 bug：拖拽/点击 effect 依赖了 `frame`，帧流每 ~100ms 更新导致 effect 反复重建并重置拖拽状态 → mouseup 永远发不出去（点击无效，输入框得不到焦点，打字自然无效）。修复：effect 去掉 `frame` 依赖；另新增**点击画面后键盘直输**（ASCII + 常用键；中文用下方输入行） |

### 验证（四轮）
