## 改动点

### 2.1 统一可视化描述符（后端）

**新文件** `server/map-visual.mjs`：

```js
{
  v: 1,
  id, title,
  kind: "flow" | "heatmap" | "choropleth" | "categorical" | "points",
  geojson: <FeatureCollection>,
  stats: { count, min, max, avg, ... },
  styleHint: { field, ramp, widthRange, radiusRange },   // 纯数据，非 MapLibre 表达式
  provenance: { dataset, generatedBy, runId, at },
}
```

**适配既有端点（不改其响应形状）**：新增 `GET /api/map/visual?dataset=&kind=&threshold=`，内部把 M2/M3/柬埔寨/演示四类端点适配为描述符。旧端点继续服务旧调用方与验证脚本。

### 2.2 统一"可视面板"（前端）

```
┌─ 可视面板 ────────────────────────────────┐
│ [自然语言输入框]              ← 默认入口   │
│   ↓ 高级（折叠）                          │
```

**审查（独立子代理）发现并已修复的缺陷**（阶段 2 相关）：

1. **线类数据出图空白**：M2 流量带宽与公交线路是纯 LineString 几何，`showAnalysisRich` 只处理 Point/Polygon——卡片显示"已生成"但地图上没有任何图层。现在线类描述符走线图层渲染（L3 有真断言）。
2. **连续出图叠加残留**：第二次出图不清第一次的图层，且两套渲染路径（演示/适配器）的图层 id 族不同。现在统一走 rich 路径并在渲染前清上一次（L3 有真断言）。
3. **浮动条「清除」清不掉可视面板的图层**：`clearAllAnalysis` 只遍历旧路径登记的 id，rich 路径从未登记；且面板关闭后没有别的 UI 入口能清除。现在 `showAnalysisRich` 登记 id 并注册重放，清除按图层前缀兜底扫描。
4. **临时层不受样式重载保护**：rich 路径的图层不在重放注册表里，改样式颜色就会消失（阶段 2 验收 C3 实际不成立）。现在纳入注册表。
5. **Chat 模式可绕过保存限制**：保存按钮只提示不阻止。现在真正 disabled + `save()` 内部拦截。
6. **顶栏「图层」是死按钮**：`leftHidden` 只改了 aria 属性，左栏没有真的收起。现在按钮真的开合左栏。
7. **「撤销」能力丢失**：原"示例数据"菜单的撤销在收敛时漏掉。现在结果卡片有撤销按钮。
8. **地图状态行的区域名永远不会出现**：`mapContext.regionName` 没有生产者。现在视口上报时带上当前下钻区域名。

**测试**：`test:map-visual`（源码断言）+ `test:map-visual:live`（真实 Chromium：三组图层树、四类数据源出图、样式重载后临时层仍在、连续出图不叠加、Chat 模式保存被禁用）。已进 CI。

**对照计划补齐（2026-10-10 二次核对）**：§2.2 的结果卡片操作原设计为「[显隐] [删除] [保存]」，实现里此前缺"显隐"——现已补上（`toggleVisible` → `MapViewer.setAnalysisVisibility`，对照底图时常用），L3 有真实可见性断言（用 `getLayoutProperty` 读，`getLayer().layout` 读不到运行时更新）。
