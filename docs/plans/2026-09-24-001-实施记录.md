## 二、代码改动清单

**服务端**
- `server/runs.mjs`：新增 `recordRunFinalText()`（同 Run 至多一条 `assistant_final`；同文本幂等 no-op；修正时更新同一条并递增 `version`）；`recordRunEvent` 对 `assistant_final` 走幂等路径；`finishRun` 将 `completion` 绑定 `runId`、追加稳定 `finalText`/`finalMessageId` 并在 `run_finished` 携带。
- `server/运行轨迹.mjs`：新增 `applyObjectiveDowngrade()`。
- `server/agent.mjs`：`_promptEntry` 重置 `lastFinalText`/`suppressFinalText`；`agent_settled` 终稿写入受 `!suppressFinalText` 约束；收尾提醒回合包在 `suppressFinalText` 中。
- `server/index.mjs`：`getRunFinalText` 优先读 Run 根级 `finalText`；5 处 `run_finished` 事件补 `finalMessageId`。

**前端**
- `client/src/事件展示.js`：新增 `runConclusion()` 与 `toolIdentity()`；`flowEventTone`/`flowEventLabel` 对 `run_finished` 改为按终态生成。
- `client/src/components/ChatPanel.jsx`：`ThinkingBlock` 默认收起、按钮 + `aria-expanded`/`aria-controls`、思维脑图标；`ToolCard`、结果卡工具列表、执行流工具项接入 `ToolIdentityIcon`。
- `client/src/components/工具语义图标.jsx`（新）：`ToolIdentityIcon` 组件。
- `client/src/components/Icon.jsx`：新增 `brain`（路径取自 Lucide，ISC）。
- `client/src/components/SettingsPanel.jsx`：`thinkingDefaultOpen` 默认改为 `false`。
- `client/src/styles.css`：思考头按钮化与 `:focus-visible`、`.tool-identity`、终态 `warning` 点色。

**测试与文档**
- `scripts/任务结论事件流测试.mjs`（新，`test:conclusion`）：终态映射、工具图标全量覆盖、客观降级、隔离 Run Store 终稿幂等、静态契约。
- `scripts/对话流性能回归测试.mjs`：更新“思考块默认展开”为“默认收起（尊重设置）”。
- `package.json`：注册 `test:conclusion`。
