# 文件树、上下文与模型供应商改造设计

## 目标

修复工作区文件树目录切换和返回根目录的问题，增加整个工作区的递归名称搜索；让思考块按内容自适应且不超过 240px；让上下文额度使用模型真实窗口；完善审批接口诊断；在现有模型设置中增加供应商和多模型配置管理。

## 文件树与搜索

- 修复空目录参数被旧目录回退的问题。
- 目录请求使用序号保护，较早请求不能覆盖较晚的目录结果。
- 新增工作区递归搜索接口，匹配文件名、目录名和相对路径。
- 搜索结果显示相对路径；目录可进入，文件可直接打开。
- 跳过隐藏目录和常见依赖/构建目录，并限制结果数量。

## 对话运行状态

- 思考块默认遵循设置，内容高度自适应，内容区最大 240px，超出内部滚动。
- 上下文窗口优先使用模型元数据，缺失时使用 1M 估算值并标识估算来源。
- 顶部上下文状态、上下文环、自动压缩阈值使用同一份上下文数据。
- 审批模式继续使用 `ask/auto` 与 `allow/always/deny`，前端对 404 提供前后端版本不一致提示。

## 模型供应商

- 供应商配置写入规聚独立模型配置，凭据写入独立凭据文件，API Key 只返回掩码。
- 支持 OpenAI Chat Completions、Anthropic Messages、OpenAI Responses。
- 每个供应商支持启用状态、Base URL 和多个模型；模型支持名称、上下文上限、思考、图片和启用状态。
- 提供列表、创建/更新、删除和测试连接；保存后重置 Pi Model Runtime 并刷新目录。
- 保留现有模型选择、导入 Pi 配置和真实连接测试链路。

## 验证

- 增加文件树根目录返回、递归搜索、供应商配置脱敏和模型目录刷新测试。
- 运行现有验证脚本、对话流/Pi 配置测试、服务端语法检查和前端构建。
