# 知识图谱探索交互设计说明

## 1. 背景

当前知识图谱已经具备力导向布局、按类型过滤、局部图谱和悬停高亮能力，但交互仍然偏向“查看一张图”：

- 单击节点直接打开文档，无法停留在图谱中观察关系；
- 高亮只在悬停期间存在，鼠标移开后探索上下文消失；
- 局部图谱需要手动切换，不能沿着邻居连续浏览；
- 图谱右侧没有针对当前节点的关系清单，用户需要在大量节点中寻找下一步；
- 缩放时批量更新所有节点标签，关系图较大时会影响流畅度。

本次改造目标是把图谱变成连续的知识探索入口，交互逻辑参考 Obsidian 的局部关系观察，同时保留全图上下文。

## 2. 目标与非目标

### 2.1 目标

1. 用户单击节点后，能够明确知道当前正在探索哪个节点。
2. 当前节点的一跳邻居和关系边持续高亮，其他节点弱化但不消失。
3. 用户可以从图上或关系面板点击邻居，连续进入下一个探索中心。
4. 用户可以通过历史回退、回到全图恢复浏览路径。
5. 用户仍然可以快速打开文档，且“探索”和“打开文档”不互相干扰。
6. 大图缩放与探索状态切换不触发不必要的全量节点更新。

### 2.2 非目标

- 本次不引入新的图数据库或服务端实时推送；
- 本次不重做现有力导向布局算法；
- 本次不改变知识库文档树、文档预览和现有搜索流程；
- 本次不要求一次性解决全部历史断链，但会为后续断链修复保留清晰的交互入口。

## 3. 核心交互流程

### 3.1 节点操作

| 操作 | 行为 |
| --- | --- |
| 单击节点 | 将节点设为“当前探索中心”，持久化显示其一跳邻居和关系边；不立即打开文档 |
| 双击节点 | 打开对应文档；标签节点继续触发标签搜索 |
| 点击关系面板中的邻居 | 将邻居设为新的探索中心，并将其加入探索历史 |
| 点击画布空白区域 | 清除当前探索中心和关系高亮，恢复全图 |
| 点击“返回上一步” | 回到上一个探索中心；没有历史时按钮禁用 |
| 点击“回到全图” | 清空探索中心、关系面板和探索历史，并适配全图 |
| 悬停节点 | 只提供轻量的临时提示，不覆盖持久化探索状态 |

单击与双击之间需要避免误触：单击探索动作延迟一个很短的双击判定窗口，双击发生时取消打开/切换竞争动作，最终以双击打开文档为准。

### 3.2 当前探索态

选中节点后：

- 当前节点使用 `focus` 状态；
- 一跳邻居使用 `neighbor` 状态；
- 当前节点与邻居之间的边使用 `near` 状态；
- 其他节点和边使用 `dim` / `dim-edge` 状态；
- 图谱不重建、不重新请求数据、不切换为只有一跳节点的局部图，以保留全图空间位置和上下文；
- 当前节点存在于视口外时，平滑移动视图使其进入可见区域。

### 3.3 关系面板

关系面板固定在图谱右侧，显示当前探索中心的标题、类型和关系统计。关系按现有边类型分组：

- 双向链接：`link`；
- 内容相似：`similar`；
- 标签关系：`tag`；
- 目录关系：`folder`。

每条关系显示目标节点名称、节点类型和必要的路径信息。点击关系条目等同于点击图上的邻居。没有关系时显示明确的空状态，而不是空白区域。

## 4. 状态设计

组件新增以下前端状态，不改变服务端图谱数据结构：

- `selectedId`：当前探索中心；
- `exploreHistory`：探索中心的有序历史，重复进入同一节点时不连续堆叠；
- `selectedNeighbors`：由邻接表计算的一跳邻居；
- `zoomLabelsVisible`：标签显示阈值状态，仅在阈值跨越时更新。

`selectedId` 变化只更新 G6 元素状态，不触发图谱实例销毁和重建。父组件的 `highlightId` 仍然用于标识当前打开的文档，两者可以同时存在但职责不同：

- `selectedId` 表示“正在探索的节点”；
- `highlightId` 表示“当前文档节点”。

## 5. 性能约束

1. 探索切换不得重新调用图谱接口。
2. 探索切换不得因 React 状态变化重建 G6 实例。
3. 关系高亮优先使用现有 `setElementState`，不通过批量修改节点数据实现。
4. 缩放标签更新使用阈值变化检测和 `requestAnimationFrame` 节流，避免每个滚轮事件遍历全量节点。
5. 关系面板只渲染当前节点的邻居，不渲染全量边列表。
6. 对 400—500 个节点规模的知识库，单击探索和连续点击邻居应保持可操作，不出现持续布局抖动。

## 6. 验收标准

- [ ] 单击节点不会直接打开文档，而是显示持久化探索态和关系面板。
- [ ] 当前节点、邻居、相关边、非相关节点的视觉层级清晰可辨。
- [ ] 点击图上邻居或关系面板条目可以连续探索至少三层关系。
- [ ] 双击文件节点可以打开文档；双击标签节点可以触发标签搜索。
- [ ] 空白点击可以恢复全图；返回上一步可以恢复上一探索中心。
- [ ] 图谱实例不会因单击探索而重新创建，布局不会重新抖动。
- [ ] 缩放时标签显示切换不会导致明显卡顿。
- [ ] 现有全图、局部图谱、过滤器、搜索定位和文档打开流程不回归。
- [ ] `npm run verify` 通过，并完成至少一次大知识库浏览回归。

## 7. 实施顺序

1. 在 `KnowledgeGraph` 中增加探索状态、历史和关系面板。
2. 将 G6 单击事件改为探索，将双击事件保留给文档打开。
3. 将持久化高亮与悬停高亮解耦，并增加画布空白点击清除。
4. 优化缩放标签更新，避免每次滚轮都更新全量节点。
5. 在 `KnowledgeBase` 中区分“探索节点”和“打开文档”回调。
6. 运行构建、API 冒烟和浏览器回归，补充变更日志。
