# 规聚汇报视频整合设计说明

## 目标

将 `规聚项目完整介绍汇报-单文件离线版.html` 调整为约24页的10分钟汇报版本，保持暖白 Claude 风格，保留原文件中的3个内嵌视频，并将新增10个录屏以相对路径放入同目录 `视频` 文件夹。

## 叙事结构

1. 开场与汇报主线
2. 为什么做规聚：规划工作的痛点、知识资产和协作目标
3. 解决什么问题：资料、知识、工具、成果进入同一闭环
4. 怎么实现：工作区、Agent、GIS、Office、工作流和工程资产
5. 功能演示与案例：文件打开、Agent提问、Skills、模板库、智能体、地图、热力图、OD及两个案例
6. 总结：工程经验沉淀成可持续的工作系统

## 媒体策略

- 新增视频使用 `视频/文件名.webm` 相对路径，支持离线打开。
- 视频统一使用 `controls muted playsinline preload="metadata"`。
- 切页时只自动播放当前页视频，离开页面暂停并回到起点。
- 通过 `data-speed` 保留视频标题中明确的倍速信息；未标注倍速的视频默认1倍速。
- 每个视频槽保留标题、功能说明和“演示重点”，避免视频成为无解释的黑盒。

## 验收标准

- 页面数量约24页，导航页数与实际页数一致。
- 原有3个内嵌视频仍存在，新增10个外置视频路径全部可解析。
- 所有视频均可在本地文件模式下加载；切页不会同时播放多个视频。
- HTML保持暖白 Claude 风格，不改成严格瑞士风。
- 视频页不遮挡底部翻页控件，桌面和较窄窗口下内容可读。
