# 知识图谱增强设计说明

日期：2026-08-17

## 目标

修复知识库关系图谱当前无法稳定渲染、节点布局异常、关系不完整和根目录切换后数据可能残留的问题，并补充一组能够直接帮助用户判断知识库健康状况的交互功能。

本次范围限定在知识库关系图谱，不改动地图、M2 宏观分析和其他工作区功能。

## 已确认问题

1. 项目使用 `@antv/g6` 5.x，但节点和边的 `animation.enter/update` 仍使用对象格式；G6 5.x 会把它当作动画数组处理，浏览器实际报出 `Wut(...).map is not a function`，导致节点绘制中断。
2. `fitView(40, "both", true)` 使用旧版 G6 的位置参数。G6 5.x 应使用 `{ direction: "both" }` 形式，并在布局完成、容器尺寸变化后重新适配。
3. 分批渲染时，追加阶段只添加后续节点之间的边，首批节点与后续节点之间的跨批次边会被遗漏。
4. 切换知识库根目录时没有立即清空旧的 `graphData`，可能短暂显示上一个根目录的图谱。
5. 相似关系缓存只按根目录索引区分，没有在扫描结果变化后失效；文档修改后可能继续使用旧的相似边。
6. 超过最大节点数时按边遍历顺序截断，结果不稳定，也无法优先保留当前选中文档及其邻接节点。
7. 当前自定义 force 布局最多执行 500 次迭代；在数百节点的知识库中会长时间占用主线程，造成抖动和卡顿。

## 方案

### 前端关系图谱

- 将节点和边动画改为 G6 5.x 支持的数组格式，保留现有动画效果。
- 将自定义 force 切换为 G6 5.x 的 d3-force，降低大图布局的计算量和主线程阻塞。
- 封装统一的视图适配函数，使用 G6 5.x `fitView` 参数；在首次渲染、`afterlayout` 和容器尺寸变化时调用。
- 为图谱增加“适配视图”和“重置视图”操作，重置时回到全量图居中的初始状态。
- 修复分批追加边：追加节点后补充所有至少有一个端点属于追加节点、且两个端点都在当前图谱范围内的边。
- 图谱工具栏显示节点数、边数和孤立节点数；数据被截断时明确显示当前上限。
- 增加关系类型图例，沿用现有双向链接、内容相似、标签和目录颜色。
- 增加断链提示：后端返回未解析的 Wikilink 数量，前端在图谱工具栏显示提示，不把不存在的目标伪装成节点。
- 保留已有的搜索、局部图谱、隐藏孤立节点、最少引用、节点类型过滤和间距控制。
- 选中节点时沿用现有打开文档/标签搜索行为，不改变用户已有操作路径。

### 后端关系图谱

- 扫描完成后清理或版本化相似度缓存，确保文件新增、删除或内容变化后重新计算。
- 图谱返回 `stats`：节点数、边数、孤立节点数、断链数和各关系类型边数。
- 超大图截断时按“当前文档及邻域优先、连接度其次、稳定 ID 最后”的规则选择节点，保证结果稳定。
- 保持现有 `nodes/edges/meta` 字段兼容，新增字段只作为补充，避免影响现有前端调用。

## 交互流程

```text
进入知识库 → 打开思维图谱
       ↓
加载图谱数据 → 显示节点/边/健康统计
       ↓
G6 渲染 → 布局完成后适配视图
       ↓
搜索、过滤、局部图谱、重置视图
       ↓
点击文档节点 → 打开文档并保持图谱状态
```

## 非目标

- 本次不引入 Web Worker；采用 G6 5.x 内置 d3-force 完成本轮性能修复。
- 本次不做节点位置持久化、路径查询、图谱导出和多级关系追踪。
- 本次不改变知识库 Markdown 解析规则，不自动修改用户文档内容。

## 验收标准

1. 在当前知识库中打开关系图谱，不再出现 `Wut(...).map is not a function`，节点和边可见。
2. 图谱首次加载后主体位于画布可视区域内，不再全部聚集在左上角。
3. 调整窗口或知识库面板尺寸后，图谱仍能正确适配画布。
4. 节点数超过 500 时，首批与后续节点之间的关系仍能显示。
5. 切换知识库根目录后，旧图谱不会残留。
6. 工具栏能看到节点数、边数、孤立节点和断链提示；点击适配/重置视图有效。
7. `npm run verify`、前端构建和浏览器回归均通过。
8. 本次提交不包含地图、M2 或其他已有未提交改动。
